# 무료 오프라인 페이지

GitHub Pages는 정적 게임 파일을 제공하므로 Render의 방 서버가 내려가도 AI 대전·연습장·도감을 실행할 수 있습니다. 이 페이지에서는 온라인 방을 만들거나 참가하지 않습니다.

## 최초 활성화

1. GitHub 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. **Actions → Publish free offline game**의 최신 실행을 확인합니다. 실패했다면 설정 후 **Re-run all jobs**로 다시 실행합니다.
4. 성공한 실행의 **deploy**에 표시되는 주소를 공유합니다. 기본 주소는 `https://yiamuge.github.io/game_project/`입니다.

공개 저장소의 GitHub Pages 무료 정적 호스팅을 사용합니다. 별도 게임 서버나 유료 서비스를 만들지 않습니다. 저장소가 비공개라면 계정의 Pages 이용 가능 여부를 먼저 확인해야 합니다. 이미 공개된 저장소의 공개 범위는 변경하지 않습니다.

이후 `codex/city-border-v0.2` 브랜치에 푸시하면 같은 주소에 최신 게임이 자동 배포됩니다. 온라인 게임과 오프라인 게임은 동일한 원본 코드·스프라이트·사운드를 사용합니다. Actions 또는 Pages 정책에 따른 제한은 적용됩니다.

## 인터넷 없이 실행

오프라인 페이지 메뉴의 **오프라인 파일 저장**을 누릅니다. 저장된 `city-border.html` 한 파일에 코드·이미지·폰트·사운드 구현을 모두 포함하므로 다운로드 후에는 외부 요청 없이 실행합니다. PC에서는 파일을 브라우저로 열면 됩니다. 모바일은 내려받은 HTML의 스크립트 실행을 지원하는 브라우저에서 엽니다.

페이지에 처음 접속하거나 새 버전을 내려받으려면 인터넷이 필요합니다. 파일은 저장 당시 버전이며, 새 버전은 다시 저장해야 합니다. 파일을 따로 저장하면 정적 페이지 자체에 접속할 수 없는 경우에도 플레이할 수 있습니다.

## 로컬 빌드

```sh
npm ci
npm run check
npm test
npm run build
```

`dist/index.html`은 Pages 진입 페이지이며, `dist/city-border.html`은 내려받는 단일 파일입니다. 두 파일 모두 외부 게임 서버에 의존하지 않습니다. 생성물은 Git에 직접 올리지 않고 Pages 배포 산출물로 전달합니다.
