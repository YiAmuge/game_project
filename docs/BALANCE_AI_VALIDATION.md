## 계산 비용

Node에서 시드 103, 이상/서포터, 플레이어도 AI 제어로 설정하고 `Game.step(1/30)`을 3,600회 실행했다. 같은 조건을 네 차례 실행해 첫 회를 제외한 중앙값을 비교했다.

| 구분 | 2분 경기 계산 시간 |
| --- | ---: |
| 밸런스·AI 적용 후, 충돌 검사 최적화 전 | 9.96초 |
| 충돌 검사 최적화 후 | 5.35초 |

실행 환경에서 계산 시간이 약 46% 감소했다. 이 수치는 렌더링을 제외한 경기 시뮬레이션 측정값이다. 충돌 검사는 무작위 배치 1,000건을 전체 검사 방식과 비교해 같은 결과를 확인했다. 걷기·스프라이트·배경·이펙트 품질은 유지했다.
