# 도시 경계 v1.0.4 패치노트

## 모제스

- 연속 기본공격의 숨 내쉬는 소리는 첫 타격에서 한 번 재생됩니다.
- 공격을 멈춘 뒤 다시 공격하면 첫 타격에서 다시 재생됩니다.
- 기본공격의 피해량·숨 소모·공격 간격과 전술기·궁극기의 사운드는 유지됩니다.

## 메인메뉴

- 노란 책 표지색과 검푸른 가장자리 그라데이션, 등을 맞댄 모제스·에즈라의 LD 실루엣 배경을 사용합니다.
- 메인메뉴 버튼은 기존 크기의 80%로 표시하고 화면 우측에 배치합니다.

메뉴·패키지·온라인 접속 버전은 v1.0.4입니다. 전체 효과와 수치는 [현재 구현 규칙](CURRENT_RULES.md)과 게임 내 도감에서 확인할 수 있습니다.
