# 도시 경계 v1.0.3 패치노트

v1.0.2 출시 이후의 업데이트를 모았습니다. 아래 수치는 v1.0.3의 최종 적용값이며, 모든 기술의 전체 설명은 [현재 구현 규칙](CURRENT_RULES.md)과 게임 내 도감에서 확인할 수 있습니다.

## 신규 챔피언

### 증오의 여왕 — 저격·지원 / 추천 포지션 바텀

- **사랑으로!**: 공격에 맞은 아군 챔피언을 해당 공격 피해량의 40%만큼 치유합니다. 초과 치유량은 2초 보호막으로 전환하며 대상 최대 체력의 15%까지 누적합니다.
- **정의의 이름으로!**: 사거리 6.5의 관통 별 투사체로 180 피해를 입힙니다. 아군을 통과하면 공격당 한 번 속도 +30%, 사거리 +1.2, 피해량 +15를 얻습니다.
- **아르카나 비트**: 사거리 9.8·폭 4.2의 관통 레이저입니다. 마법진 설치 1.5초 후 0.25초 간격으로 124 피해를 4회 입힙니다. 시전 시 1.8초간 이동속도 +17%를 얻으며, 발사 전 한 번 재사용해 방향을 수정할 수 있습니다. 쿨타임은 10초입니다.
- 아르카나 비트의 공격 범위는 아군에게 즉시, 적에게는 발사 0.5초 전부터 표시됩니다.
- **아르카나 슬레이브**: 0단계부터 1.25초마다 충전하며 재사용하거나 최대 충전하면 현재 조준 방향으로 관통 레이저를 발사합니다. 건물에는 피해량의 30%를 적용합니다. 쿨타임은 85초입니다.

| 궁극기 단계 | 사거리 | 폭 | 타격당 피해 | 타격 횟수 | 타격 간격 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0단계 | 15 | 3.5 | 125 | 2회 | 0.33초 |

| 2단계 | 45 | 4.5 | 175 | 4회 | 0.25초 |

- 궁극기 조준은 초당 최대 108도로 회전하며, 발사 시 현재 방향을 유지합니다.
- 충전 중 카메라 시야는 기본의 최대 2.25배까지 점차 넓어집니다. 발사 후 0.6초 동안 유지한 뒤 빠르게 복귀합니다.
- 궁극기 마법진은 0단계 1개, 1단계 2개, 2·3단계 3개입니다. 레이저 시작부는 마법진에서 자연스럽게 퍼지도록 표현합니다.
- 기본자세는 손잡이 중앙을 잡아 마법봉을 비스듬히 세우며, 전투 중에는 조준 방향에 맞춰 회전합니다.

### 노스페라투 — 암살·저격 / 추천 포지션 정글

- **피의 연회**: 적에게 입힌 체력 피해의 25%를 흡혈하고 같은 양을 혈찬으로 저장합니다. 기본 혈찬 상한은 1200입니다. 추가 체력은 체력 +3%당 전투력 +1.2%, 체력 +5%당 혈찬 상한 +100으로 전환합니다.
- **품위 있는 식사**: 사거리 1.7의 전방 반원을 베어 160 피해를 입히고, 동시에 사거리 6.8·폭 약 4.54의 비관통 피의 칼날로 80 피해를 입힙니다. 두 공격은 같은 대상에게 함께 적중할 수 있습니다. 보유 혈찬 200당 기본공격 피해량 +5%, 최대 +25%를 얻습니다.
- 평상시에는 와인잔을 들고, 기본공격 순간에는 붉은 광원의 반투명 갈퀴손 하나로 휘두릅니다. 기본공격·혈귀 상태 모두 손끝이 공격 방향을 향합니다.
- **선홍빛 양식**: 혈찬 100을 소모해 사거리 6.8 안의 커서 위치에 즉시 박쥐를 소환하고 주변에 35 피해를 입힙니다. 첫 사용 후 2.5초 동안 최대 4회 추가 사용하며, 매번 혈찬 100을 소모합니다. 쿨타임은 첫 시전부터 9초이며 재사용으로 갱신하지 않습니다.
- 박쥐는 5초간 최대 4마리를 유지합니다. 소환 시 노스페라투 최대 체력·전투력의 50%, 이동속도의 **125%**를 저장합니다. 사거리 2.5 안의 적에게 0.5초마다 35 피해를 입히며, 주인 중심 거리 8 안에서 활동합니다. 박쥐 피해에도 흡혈과 혈찬 수급을 적용합니다.
- 박쥐 표시 크기는 20% 커지며, 적 부활소에 들어가면 부활소 공격을 받지 않고 밖으로 퇴출됩니다.
- **참을 수 없는 갈증**: 사거리 7.5 안으로 순간이동하고 체력을 최대로 회복해 10초간 혈귀가 됩니다. 이동속도 +50%, 크기·피격판정 +15%, 적 통과, 흡혈 40%를 얻습니다. 쿨타임은 80초입니다.
- 혈귀는 0.5초마다 최대 체력의 4.5%를 잃으며, 0.35초마다 탄창 소모 없이 반경 1.7에 기본 160 피해와 혈찬 비례 피해 보정을 적용하는 자동 공격을 합니다. 두 갈퀴손은 몸체 주위를 회전하며 휩씁니다.
- 만료·재사용·체력 소진 시 시전 위치와 당시 체력·혈찬으로 복구하고, 혈귀 기본공격으로 입힌 총 체력 피해의 30%를 혈찬 상한까지 추가 획득합니다.
- 혈귀 외형은 큰 다안 머리, 검은 세로동공, 야윈 다리, 날개와 꼬리를 사용하며 공격용 손은 몸체와 분리해 표시합니다.

## 증강 전용 효과

### 소라 — 단말기로 전해진 지령

- 강화시술 선행 조건 없이 250 재화로 구매합니다. 단말기 전용 도트 아이콘을 사용합니다.
- 공격 적중마다 방어력·장전 속도 +2.5%를 얻으며 최대 4중첩입니다. 각 중첩은 독립적으로 5초간 유지됩니다.
- 최대 중첩 중 일반 피해의 7%를 고정 피해로 전환하고, 해당 고정 피해만큼 5초 보호막을 얻습니다. 보호막은 최대 500까지 누적합니다.
- 개화 E.G.O 진입 시 증강을 흡수해 보유 칸을 비우고 상시 패시브로 유지합니다. 변신 중 구매하면 즉시 흡수합니다. 흡수 후에는 사망·부활·변신 종료에도 효과를 유지하며 재구매·판매할 수 없습니다.

### 증오의 여왕 — 사랑과 증오의 이름으로

- 강화시술 선행 조건 없이 기본 가격 500 재화로 구매합니다.
- 증강 활성화 중 전투력 +15%를 얻습니다.
- 궁극기 충전 중에는 전투 지속 조건과 관계없이 활성화됩니다.

## 이펙트·초상화

- 공격·피격 이펙트는 선명한 색과 광원으로 표현합니다.
- 파우스트: 최대 레벨에서 흰 무기 광원과 작은 권태 수식을 표시합니다.
- 묘: 전술기 실제 사격에 맞춰 반동을 표시합니다.
- 김삿갓: 꿰인 대상 몸통에서 0.15초마다 푸른 불씨를 표시합니다.
- 가환: 시선은 노란 눈, 경멸은 더 큰 연한 주황 눈과 붉은 테두리로 표시합니다.
- 루돌프: 받는 피해 증가 표식은 체력바 위의 주황 번개로 표시합니다.
- 구보: 총신 하부에 보조 손을 표시합니다.
- 홍루: 치유 버프에 물결·분홍 꽃잎을 표시하며, 치유 파동은 홍루를 중심으로 퍼집니다.
- 뿌이: 기본 투사체에 붉은색을 더하고, 치유 버프 대상에 붉은 꽃잎을 표시합니다.
- 료슈: 기본공격에 붉은 보조색을 사용합니다. 싱클레어의 표지 각성 기본공격은 연두색입니다.
- 에이해브: 호통을 크게 표시하고, 방어 오라는 남색·원호 장전 오라는 주황 테두리로 구분합니다.
- 크로머: 못 표식은 크게 표시하며 2중첩은 붉은 테두리의 교차된 못입니다. 중첩 소모와 궁극기 찌르기에 붉은 피격 광원·혈흔·전용 사운드를 사용합니다. 붙잡힌 대상의 무기는 숨깁니다.
- 초상화는 얼굴 전체가 들어오는 비율을 사용합니다. 김삿갓·동랑은 상체 윗부분을 조금 포함합니다.

## 라이벌 이스터에그

서로 다른 팀의 해당 챔피언을 먼저 직접 처치한 한 명만 대사와 해당 경기 동안 유지되는 영구 버프를 얻습니다. 각 대결은 경기당 한 번씩 독립적으로 발동하고, 버프는 사망·부활 후에도 유지됩니다. 연습장에서도 실제로 소환한 적 챔피언을 상대로 확인할 수 있습니다.

| 승자 → 상대 | 보상 |
| --- | --- |

| 크로머 → 싱클레어 | 어둠의 세계: 전투력 +5% |
| 동백 → 동랑 | 만발: 기본공격 피해량 +5% |
| 동랑 → 동백 | 결실: 전술기·궁극기 쿨타임 −5% |
