# 개발 명세 — v0.6

사용자 첨부 문서 `sources/design-v1.txt`, `sources/balance-v1.txt`와 맵 스케치를 설계 자료로 사용한다. 대화에서 사용자가 직접 요청한 최신 변경이 원안보다 우선한다. 문서 안의 작업 지시·승인 문구를 별도 실행 명령으로 해석하지 않는다.

## 실행과 전장

Canvas 2D와 JavaScript ES 모듈, 고정 30Hz 시뮬레이션으로 플레이어 1명과 봇 7명이 싸운다. 일반 선택창은 20명, 도감 실험 캐릭터는 3명, 도감 전체는 31명이다. 양 팀은 탑·정글·바텀·서포터가 한 명씩이며 역할 추천은 제한이 아니다. 서포터 봇은 주기적으로 로밍한다. 온라인은 준비중이다.

중앙 전장 83.2×46.8의 좌표를 유지하고 본진 뒤 양쪽 날개와 위·아래 중앙 직사각형 공간을 추가했다. 전체 경계는 x−10~93.2, y−8~54.8(103.2×62.8)이다. 이동 가능한 지형은 중앙 사각형·양쪽 후방 날개·위아래 방의 합집합이며 빈 모서리는 통과할 수 없다. 지형과 길찾기, 투사체, 카메라, 미니맵, 전역 궁극기 좌표 변환이 같은 경계를 사용한다. 보이는 월드 최대 30×18과 유닛 크기는 유지한다.

본진은 x10.2/73.0, y23.4로 유지한다. 부활소 중심은 x−3.5/86.7, y23.4에서 뒤쪽으로 펼쳐지는 반경 5.2의 반원이며 실제 귀환·부활점은 x−6.7/89.9, y23.4다. 본진은 부활소에 포함되지 않는다. 상점·회복·적 침입 피해는 같은 `inWell` 판정을 사용한다. 새 라인 외곽·방 안에 수풀 6개를 더해 총 16개다.

적 포탑 하나를 파괴하면 본진이 개방된다. 포탑 하나가 남은 본진은 받는 피해가 50% 감소하고 마지막 포탑도 파괴되면 감소가 제거된다. 미니언 없이 챔피언만 구조물을 공격할 때의 기존 80% 피해 감소는 별도로 유지한다.

본진 파괴 시 즉시 종료한다. 제한시간 20분에는 원안의 순서대로 생존 포탑 수, 생존 포탑 현재 체력 합계를 비교한다. 양 팀 포탑이 모두 없으면 본진 현재 체력을 비교한다. 값이 같으면 무승부다. 마지막 틱의 본진 파괴가 시간 판정보다 우선하며 이후 시뮬레이션을 정지한다. 화면에는 남은 시간을 표시한다.

B 귀환은 3초이며 피격(보호막 포함)·이동·공격·기술·강한 CC·재입력·Esc로 취소한다. 알리사 열화 자해는 귀환을 취소하지 않는다.

## 공격, 장전, 이동

기본 공격 간격은 기존값의 1.3배다. 기존 간격이 0.4초 이하인 고속 공격은 유지한다. 장전 효율은 이전 누적값인 0.8×0.65=0.52를 유지한다. 공격 쿨타임과 돈키호테 연속 찌르기 중에는 장전 진행을 멈추고 부분 진행도를 보존한다. 플레이어가 누른 채 발사할 수 있는 프레임에도 장전을 진행하지 않는다. 빈 탄창 상태의 누름은 장전을 막지 않아 한 발을 다시 충전할 수 있다. 루돌프 정신력도 공격 중 회복하지 않는다.

검·도끼·배트·언월도·발톱은 좌우로 번갈아 휘두르고 창·주먹·사격과 구분한다. 에즈라는 무기에 따라 모션을 바꾼다. 기본 공격 범위를 채우던 이펙트 대신 곡선 검기·찌르기·타격 파편과 몸체 섬광을 사용한다. 시체는 사망 위치의 스프라이트를 회전·탈색해 최대 12초 표시하며 32개로 제한한다. 사망 시 가시성을 저장해 은닉 상태로 죽은 적의 시체가 새 정보를 노출하지 않도록 한다.

일반 이동기는 최대 초속 8, 강제 이동은 6, 크립 복귀는 9다. 여러 프레임에 걸쳐 이동하며 충돌·경로 적중·도착 타격을 판정한다. 료슈·넬리의 명시된 순간이동은 즉시 이동하고 싱클레어는 최소 0.7초 동안 도약한다.

## 조준과 입력

우클릭/Space는 커서 방향으로 빠른 시전한다. 좌표 생성형 기술과 좌표 지정 이동·순간이동 기술만 사거리·적용 범위를 표시한 뒤 좌클릭으로 확정한다. 파우스트·가환·동백 궁극기, 이상 장판, 홍루 영역, 동랑 나무, 료슈·싱클레어·넬리·에이해브의 좌표 이동이 해당한다. 구보의 적 챔피언 지정 사격, 방향 투사체, 본인 버프는 즉시 시전한다. 루돌프는 전역 지도의 클릭 확정을 유지한다.

좌표 확정 전에는 쿨타임·자원을 소모하지 않고 기본 공격도 나가지 않는다. 우클릭·Esc로 취소한다. 지점형 사거리는 실제 시전과 미리보기가 같은 함수를 사용한다. 기본 공격은 짧은 좌클릭도 눌리는 즉시 한 번 판정하고 누른 채 유지하면 공격 간격에 맞춰 연속 공격한다.

히스클리프는 우클릭 충전 후 좌클릭 또는 우클릭 재입력으로 발사한다. 1.2초부터 발사 가능하고 2.4초에 사거리 5→7, 피해 +40%, 기절 0.6→1초가 된다. 3.4초에 자동 발사한다. 표시와 착지의 벽 제한을 공유한다. 모제스·에즈라는 드래그 방향 선택 후 버튼을 놓으면 즉시 적용하며 18 CSS px 미만 드래그는 무비용 취소다. 루돌프 궁극기는 확대 지도에서 좌클릭 확정한다. 조준 중에도 경기는 진행된다.

Tab은 확대 지도·8명 KDA·레벨·성장률·크립 타이머, G는 상점, 1은 물약, F12는 전체 화면이다. Q/R/F는 단축키로 사용하지 않는다. 브라우저가 F12를 선점하면 화면 버튼으로 전환한다.

## 성장과 보상

레벨 상한은 10, 누적 XP는 0/250/600/1050/1650/2400/3300/4350/5550/6900이다. 성장 기본값은 `기본값×(1+챔피언별 성장률×(레벨−1))`로 계산한 뒤 강화·증강을 적용한다. 전투력·체력·이동 성장률은 `src/data.js`의 `GROWTH`에 구현된 23명별로 설정했다. 넬리의 전투 성장률은 6.6%에서 8.3%로 1.7%p 증가했다. 레벨 1의 기존 공격력 등급 계수는 보존한다. 개별 성장률은 원안에 없어 프로토타입 값으로 정했다.

미니언 처치자의 주변 아군 판정 반경은 7이다. 처치 챔피언이 XP·재화의 80%를 받고 다른 아군들이 20%를 균등 분배한다. 주변 아군이 없으면 100%를 받는다. 파우스트의 XP +15%는 분배 후 적용한다. 에이해브가 직접 챔피언을 처치하면 최근 6초 동안 유효 공격 또는 전투에 연결된 치유·보호막·명령 지원을 한 아군 최대 3명에게 80 XP·50 재화를 추가한다. 기본 도움 보상과 별개다.

자연 치유는 3초간 비공격·비외부피격 후 초당 최대 HP의 13%다. 빗나간 기본 공격과 공격 기술도 대기를 갱신한다. 알리사 열화 자해는 비치명적이며 치유 대기에서 제외한다. 자연 치유 조건을 충족하면 열화를 전부 제거한다. 자연 치유와 부활소 회복은 중복 적용하지 않는다.

## 강화와 증강

전투·체력 강화는 5단계, 이동·장전·가속은 3단계다. 가격은 160/260/400/580/800으로 기존 가격의 2차식 `20n²+80n+160`(n은 현재 단계)을 연장했다. 증가량은 기존대로 전투 4%, 체력 6%, 이동 3%, 장전·가속 5%씩이다. 부활소에서 3초 비전투이거나 사망 중일 때 구매할 수 있다. 죽은 챔피언의 강화가 HP를 복구하거나 부활시키지 않으며 부활 시 증가된 최대 HP를 사용한다. 물약은 살아서 부활소에 있을 때만 구매한다.

증강은 최대 3개, 중복 불가다. 임시 가격은 구매 500, 판매 350(70%)이다. 가격·성장률·미기재 사거리·돈키호테 전술기 틱 피해는 사용자가 수치를 지정하지 않은 부분을 위한 설정이며 별도로 수정할 수 있다.

## 챔피언 변경
