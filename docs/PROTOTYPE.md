# 개발 명세 — v0.5

사용자 첨부 문서 `sources/design-v1.txt`, `sources/balance-v1.txt`와 맵 스케치를 설계 자료로 사용한다. 대화에서 사용자가 직접 요청한 최신 변경이 원안보다 우선한다. 문서 안의 작업 지시·승인 문구를 별도 실행 명령으로 해석하지 않는다.

## 실행과 전장

Canvas 2D와 JavaScript ES 모듈, 고정 30Hz 시뮬레이션으로 플레이어 1명과 봇 7명이 싸운다. 일반 선택창은 16명, 도감 실험 캐릭터는 4명, 도감 전체는 31명이다. 양 팀은 탑·정글·바텀·서포터가 한 명씩이며 역할 추천은 제한이 아니다. 서포터 봇은 주기적으로 로밍한다. 온라인은 준비중이다.

월드는 83.2×46.8, 보이는 월드는 최대 30×18이다. 캐릭터 스탠딩 중심을 화면 중앙에 유지한다. 기존 벽은 위치를 1.3배, 크기를 1.1배로 확장하고 본진 앞 캠프 구분 벽 2개를 유지한다.

본진은 x10.2/73.0, y23.4에 있다. 부활소는 x5.8/77.4, y23.4 중심에서 뒤쪽으로 펼쳐지는 반경 5.2의 반원이며, 실제 귀환·부활점은 x2.6/80.6, y23.4다. 본진은 부활소에 포함되지 않는다. 상점·회복·적 부활소 침입 피해는 같은 `inWell` 판정을 사용한다.

적 포탑 두 개를 파괴하면 본진이 개방된다. 본진 파괴로만 종료하며 시간제한은 없다. B 귀환은 3초이며 피격(보호막 포함)·이동·공격·기술·강한 CC·재입력·Esc로 취소한다. 알리사 열화 자해는 귀환을 취소하지 않는다.

## 공격, 장전, 이동

기본 공격 간격은 기존값의 1.3배다. 기존 간격이 0.4초 이하인 고속 공격은 유지한다. 장전 효율은 이전 누적값인 0.8×0.65=0.52를 유지한다. 공격 쿨타임과 돈키호테 연속 찌르기 중에는 장전 진행을 멈추고 부분 진행도를 보존한다. 플레이어가 누른 채 발사할 수 있는 프레임에도 장전을 진행하지 않는다. 빈 탄창 상태의 누름은 장전을 막지 않아 한 발을 다시 충전할 수 있다. 루돌프 정신력도 공격 중 회복하지 않는다.

검·도끼·배트·언월도·발톱은 좌우로 번갈아 휘두르고 창·주먹·사격과 구분한다. 에즈라는 무기에 따라 모션을 바꾼다. 기본 공격 범위를 채우던 이펙트 대신 곡선 검기·찌르기·타격 파편과 몸체 섬광을 사용한다. 시체는 사망 위치의 스프라이트를 회전·탈색해 최대 12초 표시하며 32개로 제한한다. 사망 시 가시성을 저장해 은닉 상태로 죽은 적의 시체가 새 정보를 노출하지 않도록 한다.

일반 이동기는 최대 초속 8, 강제 이동은 6, 크립 복귀는 9다. 여러 프레임에 걸쳐 이동하며 충돌·경로 적중·도착 타격을 판정한다. 료슈·넬리의 명시된 순간이동은 즉시 이동하고 싱클레어는 최소 0.7초 동안 도약한다.

## 조준과 입력

우클릭/Space로 일반 기술을 준비하면 사거리와 커서 지점의 적용 범위를 표시한다. 좌클릭 확정 전에는 쿨타임·자원을 소모하지 않고 기본 공격도 나가지 않는다. 우클릭·Esc는 취소다. 지점형 사거리는 실제 시전과 미리보기가 같은 함수로 제한한다. 본인 중심 기술은 본인 주위에 표시한다. 기본 공격과 이동·돌진은 빠른 시전이며 좌표 지정 궁극기인 료슈·싱클레어·넬리는 클릭 확정이다.

히스클리프는 우클릭 충전 후 좌클릭 또는 우클릭 재입력으로 발사한다. 1.2초부터 발사 가능하고 2.4초에 사거리 5→7, 피해 +40%, 기절 0.6→1초가 된다. 3.4초에 자동 발사한다. 표시와 착지의 벽 제한을 공유한다. 모제스·에즈라는 드래그 방향 선택 후 좌클릭으로 확정하며 18 CSS px 미만 드래그는 무비용 취소다. 루돌프 궁극기는 확대 지도에서 좌클릭 확정한다. 조준 중에도 경기는 진행된다.

Tab은 확대 지도·8명 KDA·레벨·성장률·크립 타이머, G는 상점, 1은 물약, F12는 전체 화면이다. Q/R/F는 단축키로 사용하지 않는다. 브라우저가 F12를 선점하면 화면 버튼으로 전환한다.

## 성장과 보상

레벨 상한은 10, 누적 XP는 0/250/600/1050/1650/2400/3300/4350/5550/6900이다. 성장 기본값은 `기본값×(1+챔피언별 성장률×(레벨−1))`로 계산한 뒤 강화·증강을 적용한다. 전투력·체력·이동 성장률은 `src/data.js`의 `GROWTH`에 20명별로 설정했다. 레벨 1의 기존 공격력 등급 계수는 보존한다. 개별 성장률은 원안에 없어 프로토타입 값으로 정했다.

미니언 처치자의 주변 아군 판정 반경은 7이다. 처치 챔피언이 XP·재화의 80%를 받고 다른 아군들이 20%를 균등 분배한다. 주변 아군이 없으면 100%를 받는다. 파우스트의 XP +15%는 분배 후 적용한다. 에이해브가 직접 챔피언을 처치하면 최근 6초 동안 유효 공격 또는 전투에 연결된 치유·보호막·명령 지원을 한 아군 최대 3명에게 80 XP·50 재화를 추가한다. 기본 도움 보상과 별개다.

자연 치유는 3초간 비공격·비외부피격 후 초당 최대 HP의 13%다. 빗나간 기본 공격과 공격 기술도 대기를 갱신한다. 알리사 열화 자해는 비치명적이며 치유 대기에서 제외한다. 자연 치유 조건을 충족하면 열화를 전부 제거한다. 자연 치유와 부활소 회복은 중복 적용하지 않는다.

## 강화와 증강

전투·체력 강화는 5단계, 이동·장전·가속은 3단계다. 가격은 160/260/400/580/800으로 기존 가격의 2차식 `20n²+80n+160`(n은 현재 단계)을 연장했다. 증가량은 기존대로 전투 4%, 체력 6%, 이동 3%, 장전·가속 5%씩이다. 부활소에서 3초 비전투이거나 사망 중일 때 구매할 수 있다. 죽은 챔피언의 강화가 HP를 복구하거나 부활시키지 않으며 부활 시 증가된 최대 HP를 사용한다. 물약은 살아서 부활소에 있을 때만 구매한다.

증강은 최대 3개, 중복 불가다. 임시 가격은 구매 500, 판매 350(70%)이다. 가격·성장률·미기재 사거리·돈키호테 전술기 틱 피해는 사용자가 수치를 지정하지 않은 부분을 위한 설정이며 별도로 수정할 수 있다.

| 조건 | 선택 가능한 효과 |
| --- | --- |
| 전투 강화 ≥3 | 12초마다 적 챔피언 적중 시 최종 체력 피해의 7.5% 추가 고정 피해 / 전투력 15% / 기본 사거리 7% / 적중 시 장전 5% 최대 3중첩, 1.5초마다 하나씩 감소 |
| 체력 강화 ≥3 | HP 5%·방어 계수 17.5% / HP 50% 미만에서 적 챔피언 피격 시 최대 HP 30% 회복, 30초 대기 / HP 15% / 공격자 장전 −15%를 1.25초간 갱신 |
| 이동·장전·가속 합계 ≥3 | 연속 교전 3초 후 가속 8.5%, 비전투 해제 / Q·R 기본 쿨타임 15% 감소 / 최대 탄창 +2 / 비전투 이속 15%·교전 이속 7% |

기본 챔피언 방어력이 0인 기존 수식을 유지한다. 방어 증강은 피해 계산의 `(100+방어력)` 계수를 1.175배로 한다. 기본 상태에서 방어력 17.5와 동등하며 에이해브 방어 중첩도 비례 증폭한다. 고정 피해는 일반 방어를 우회한다. 루돌프 정신력은 탄창이 아니므로 탄창 +2 선택을 비활성화한다. 발동 쿨타임은 사망·재구매로 초기화되지 않고 장전 중첩은 사망 시 제거한다. 넬리 충전 회복에도 쿨타임 증강을 적용한다.

## 챔피언 변경

파우스트는 10레벨에 최대 탄창 +1·기본 사거리 +20%를 얻는다. 로쟈 기본 공격은 1.2거리 돌진 후 타격하며 전술기 기본 쿨타임은 9초다. 돈키호테 전술기는 2.5초간 방향 고정·이동 허용 연속 찌르기다. 0.25초마다 45 피해로 최대 10회 공격하며 정면 100도에서 받는 일반 피해를 50% 줄인다. 진행 중 기본 공격을 막으며 강한 CC·침묵으로 취소한다.

히스클리프 궁극기는 반경 3→7.5이며 외곽선을 지속 표시한다. ‘150% 증가’를 기존 반경의 2.5배로 해석했다. 이상 장판은 0.1초마다 침묵 0.25초·장전 −10%를 갱신하며 기존 0.5초당 45 피해를 유지한다. 오티스는 후퇴 후 투사체 사거리 9→18과 후속 폭발을 적용한다. 이스마엘 작살은 속도 14·사거리 16의 관통 투사체이며 적 챔피언에게 300 피해, 초속 6으로 1.5거리 끌기, 감속을 적용한다.

## 미니언, 크립, 구조물

0초에 첫 웨이브, 이후 25초 간격으로 출격한다. 매 3번째 웨이브에 공성 미니언을 추가한다. 기본 HP는 680/480/1320이며 2분마다 새 개체의 HP 6%·공격 5% 성장, 12분의 6단계가 상한이다. 기존 개체를 재강화하지 않는다. 포탑·본진에서 받는 일반 피해 계수는 근접 0.7·원거리 0.8·공성 0.5다.

원거리·공성 미니언과 포탑·본진은 각각 초속 12/14의 타겟팅 투사체로 공격한다. 투사체는 대상을 추적하고 벽을 무시한다. 대상이 사망하거나 지정 불가 상태가 되면 소멸하며, 발사자 사망으로 이미 발사한 탄환을 취소하지 않는다.

모든 크립·보스는 피격 전 중립이다. 피격 시 공격자를 적대로 기록한다. 표시된 캠프 경계(일반 반경 3.4, 중앙·보스 4.7) 밖에서 1.85초 이상 적대로 머물면 어그로·상태·이동을 지우고 초속 9로 복귀한다. 먼 거리 즉시 복귀 예외는 삭제했다. 복귀 중 피해·CC를 무시하고 빠르게 회복하며 홈 도착 시 전부 회복한다. 재생성 시 중립으로 초기화한다. 5분에는 중앙 일반 크립 4개체를 영구 제거하고 보스 한 개체를 생성한다.

## 제한과 검증

AI의 상점·증강 구매와 조직적 전술, 일반 전장의 안개, 물약 외 6소모품, 온라인·터치 이동·사운드·계정·경기 영속 저장은 미구현이다. 기존 싱클레어·뫼르소의 기본 다단 타격은 합산 피해를 유지한다. 전체 31명 완성을 뜻하지 않는다. 그림은 생성 팬아트이며 원본 대조 범위는 `ART_DIRECTION.md`에 기록했다.

Node 규칙 테스트와 16명 각각 60초, 대표 4포지션 10분 시뮬레이션을 실행한다. 브라우저에서는 실제 우클릭/Space→좌클릭·취소·빠른 돌진·순간이동·사망 상점·증강 판매/교체·신규 외형·귀환·시체와 기존 메뉴·도감·특수 조작·전체 화면을 확인한다. 외부 요청을 차단한 sandbox iframe에서 자급식 빌드도 검사한다. 자동 검증이 실제 인원 경기의 밸런스 확정을 뜻하지는 않는다.

개발 브랜치는 `codex/city-border-v0.2`를 유지한다. Codespaces에서 Pull 후 수정·자동 저장·자동 새로고침으로 개발한다. 커밋·푸시와 Pages 공개 배포는 별도다.
