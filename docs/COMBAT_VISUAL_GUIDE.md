# 전투 시각 표현

일반 피격은 흰색·회색의 짧은 파편, 스파크와 거친 충격 자국이다. 피격된 개체를 기록하여 움직이는 몸통에 붙이고, 챔피언의 몸통 높이 1.25에서 표시한다. 물·검은 액체·명시된 핏방울은 각각 지정한 기술에서 사용한다. 물리 파편은 단단한 윤곽을 유지하며 회전하고 작아진다.

원형·부채꼴·직선 공격은 실제 판정의 반경·각도·폭을 시각 효과에 전달한다. 주 이펙트를 같은 범위에 자르고, 파티클의 바닥 좌표도 범위 안에서 표시한다. 투사체는 몸통 높이에서 날아가며 탄환·나이프·못·작살·거울 조각·얼음도끼·넓은 검파의 재질과 회전을 표시한다. 이동 궤적은 최대 5개 위치를 사용한다.

바닥 잔광은 가장 강한 최대 6개만 약하게 표시하고, 캐릭터 하이라이트의 합성 강도는 최대 0.12다. 피격은 같은 대상에 0.065초 간격으로 모아서 표시한다. 버프·보호막은 우선순위가 높은 하나의 은은한 오라를 기본으로 사용한다. 체력·탄약·상태 표시는 마지막에 그린다.

| 챔피언 | 공격·기술 | 지속 상태·버프 |
| --- | --- | --- |
| 이상 | 거울·유리 파편. 궁극기 도착에 검은 연기와 깃털. | 거울 조각 날개. |
| 파우스트 | 무채색 참격·관통. 궁극기에는 흰 빛의 영역과 상승하는 수학·물리 공식. | 권태 중 몸통 주위로 흰 공식이 상승. |
| 싱클레어 | 무채색 참격. 궁극기는 나무 참격이며 시전 체력 50% 이상은 연두색과 붉은 결, 미만은 어두운 연두색. | 표지 각성은 연두빛 오라. |
| 돈키호테 | 무채색 관통. 궁극기 돌진에는 붉은 랜스 형태의 찌르기, 노란 스포트라이트와 색종이. | 흡혈은 핏빛 연기 오라. |
| 뫼르소 | 무채색 타격. 전술기에는 부서져 날리는 금속 사슬 조각. | 전술기는 은은한 빛, 궁극기 방어 버프는 옅은 햇빛. |
| 구보 | 금속 탄환. 흉탄 중 검붉은 탄환. 궁극기는 몸통 높이의 검붉은 레이저. 패시브 부채꼴에는 다수 탄착. | 흉탄은 검붉은 불꽃 오라. |
| 김삿갓 | 푸른 참격, 넓은 베기는 밝은 청색. 붙잡힌 몸통에 스파크. | 반격 집중 중 검푸른 오라·어두운 몸, 반격 성립에 밝은 전류 신호. |
| 퀴케그 | 어두운 청록색 물 타격·관통. 연결은 꼬인 밧줄. | 연결 대상 청록색 오라, 불사는 붉게 솟는 불꽃 오라. |
| 뿌이 | 무채색 못. 치유 영역에 붉은 꽃잎. | 치유받는 아군은 붉은 꽃잎 오라. |
| 가환 | 노란 참격·관통, 피격에 소량의 핏방울. | 경멸 등의 판정 표시는 체력 UI 주변에 유지. |
| 호엔하임 | 전류를 동반한 관통. | 충전 시 1·2·3타 단계에 맞춰 전류가 강해짐. 일시 부활에도 몸에 전류. |
| 알리사 | 불꽃과 타격. 전술기 종료·재사용에 꺼지는 불씨. | 열화·화상은 몸의 불꽃, 전술기는 불꽃 오라, 자폭 대기는 붉은 불꽃 나비 날개. |
| 마튼 | 어두운 갈색 목편과 아쿠아마린 빛. 원거리 기본 공격은 지면에서 솟는 뿌리 가시. 전술기 피격 몸통에서 분자가 마튼에게 이동. | 집중·미끼는 아쿠아마린 요정. 궁극기 흡수 입자와 폭발은 반경 6.8. |
| 넬리 | 무채색 참격, 날카로운 나이프 투사체. 표식 발동에는 붉은 참격. | 체력 UI 위 식사용 나이프 표식. |
| 묘 | 주황색 참격·금속 탄환. | 궁극기는 주황색 오라·전류, 기본 공격 돌진 중 오라가 선명해짐. |
| 루돌프 | 주황색 전류와 굽은 레이저. 끝점이 지정 공격 영역 안에서 빠르게 바뀜. | 소진 시 전류 신호와 어두운 몸, 전술기 전류, 궁극기 영창은 전류와 미세 부유. |
| 동백 | 노란 꽃잎, 범위 안에서 불규칙하게 터지는 밝은 노란 폭발. | 전술기 꽃잎 오라. 무장해제 중 몸이 어두워짐. |
| 동랑 | 연갈색 물리 참격, 궁극기 착지 균열. | 욕망의 나무는 갈색 뿌리, 빛나는 욕망에는 금빛 조각. |
| 오티스 | 무채색 관통·참격. 궁극기 후속 부채꼴은 어두운 초록색과 주홍빛 화염 산탄. | 공격·후속 산탄은 실제 부채꼴 안에 표시. |
| 히스클리프 | 무채색 타격, 도약 착지 균열. 궁극기 동안 피 묻은 갈색 자루와 범위 안의 어두운 보라색 타격. | 궁극기 연장에 보라색 꽃잎. |
| 료슈 | 무채색 참격, 전술기 적중 몸통에 번뜩이는 참격. 궁극기에는 360도 화염·붉은 검기가 네 차례 회전. | 비전투 장전·가속 중 얼굴의 옅은 담배 연기. |
| 이스마엘 | 어두운 청록색 물·타격, 작살 투사체. | 생존 패시브에 주황빛 오라. |
| 홍루 | 청록색 물과 360도 참격. 궁극기 영역에 일렁이는 물결. | 공유받은 아군의 물 오라·연분홍 꽃잎, 통찰 중 물 오라. |
| 로쟈 | 무채색 참격, 기본 공격 감속에는 흰 서리. 궁극기는 회전 얼음도끼와 서리·눈꽃 영역. | 잭팟에 금속 동전이 튀며, 직접 맞아 기절한 적의 몸은 희고 푸르게 얼어붙음. |
| 그레고르 | 갈색 물리 참격과 뾰족하게 뻗는 벌레팔 찌르기. | 변이의 어두운 갈색 오라, 반경 5.5 안에서 나는 갈색 벌레. |
| 에이해브 | 어두운 청록색 물·작살, 기본 공격 범위 피해는 주황 화염 폭발. | 가스작살은 몸통의 점등, 장전·피해 전가 대상은 은은한 오라, 명령 변경은 얼굴의 외침 신호. |
| 스타벅 | 어두운 청록색 물·관통. | 궁극기는 위로 빠르게 솟아 화면 밖으로 사라지고, 착지 좌표의 위에서 빠르게 수직 낙하. |
| 소라 | 기본 상태는 푸른 흰색 타격과 들어 올렸다 찍는 수갑. 전술기 착지에 균열. 개화 상태는 검은 발톱 참격과 돌진 경로의 불규칙한 검격. | 기본·개화 상태는 각 고유 스프라이트와 몸통 지령 표식을 사용. |
| 얀 | 기본 상태는 푸른 타격·참격과 위에서 내려찍는 검, 전방 판정 안의 충격. 뒤틀림은 검은 액체 타격과 거대한 검의 착지 균열. | 손은 캐시한 낮은 밝기의 검은 오라. |

구현은 `combat-style.js`의 공격별 재질, `projectile-vfx.js`의 투사체, `champion-vfx.js`의 상태·기술 연출, `skill-vfx.js`의 제한된 파티클 풀로 구성한다. 체력·피해·쿨타임 판정과 시각 자료는 분리되어 있다.
