# 전투 시각 표현

일반 피격은 흰색·회색의 짧은 파편, 스파크와 거친 충격 자국이다. 피격된 개체를 기록하여 움직이는 몸통에 붙이고, 챔피언의 몸통 높이 1.25에서 표시한다. 물·검은 액체·명시된 핏방울은 각각 지정한 기술에서 사용한다. 물리 파편은 단단한 윤곽을 유지하며 회전하고 작아진다.

원형·부채꼴·직선 공격은 실제 판정의 반경·각도·폭을 시각 효과에 전달한다. 범위 전체에 연속적인 재질과 검기·압력 결을 깔고, 같은 범위로 잘라내어 가장자리까지 표시한다. 파티클의 바닥 좌표도 범위 안에서 표시한다. 투사체는 기본 표시 배율 2.5와 기술별 표시 크기, 충돌 반폭 배율 1.1을 적용한다. 몸통 높이에서 날아가며 탄환·나이프·못·작살·거울 조각·얼음도끼·넓은 검파의 재질과 회전을 표시한다. 이동 궤적은 최대 5개 위치를 사용한다.

바닥 잔광은 가장 강한 최대 8개에 표시하고, 캐릭터 하이라이트의 합성 강도는 최대 0.28이다. 가장 강한 빛 하나를 사용해 중복으로 밝아지는 것을 제한한다. 피격은 같은 대상에 0.065초 간격으로 모아서 표시한다. 버프·보호막은 우선순위가 높은 하나의 선명한 오라와 질감 있는 외곽광을 기본으로 사용한다. 체력·탄약·상태 표시는 마지막에 그린다.

| 퀴케그 | 어두운 청록색 물 타격·관통. 연결은 꼬인 밧줄. | 연결 대상 청록색 오라, 불사는 붉게 솟는 불꽃 오라. |

| 넬리 | 무채색 참격, 날카로운 나이프 투사체. 표식 발동에는 붉은 참격. | 체력 UI 위 식사용 나이프 표식. |
| 묘 | 단검 참격·소총의 주황색 금속 탄환. | 궁극기는 역수 쌍단검과 동공의 붉은 안광·주황색 오라, 기본 공격 돌진 중 오라가 선명해짐. |

돌진·도약은 실제 월드 위치와 높이를 최대 5프레임 기록한다. 오래된 위치일수록 몸체 잔상과 연결 궤적이 가늘고 투명해지고, 종료 후 0.18초 동안 사라진다. 강제 밀치기·즉시 순간이동은 돌진 잔상을 생성하지 않는다.

구현은 `combat-style.js`의 공격별 재질, `projectile-vfx.js`의 투사체, `champion-vfx.js`의 상태·기술 연출, `skill-vfx.js`의 제한된 파티클 풀로 구성한다. 체력·피해·쿨타임 판정과 시각 자료는 분리되어 있다.
