# 2.5D 전투 이펙트 코드

설명 기준: 현재 구현된 효과만 상세히 설명한다. 삭제된 효과·과거 버전 비교·챔피언별 대체 적용 안내는 포함하지 않는다.

[skill-vfx.js](../src/skill-vfx.js)는 HTML5 Canvas의 입체 파티클 렌더러다. Three.js 직교 카메라로 바닥 좌표와 높이를 투영하고, [render-25d.js](../src/render-25d.js)가 캐릭터와 파티클을 깊이 순서로 합성한다. 좌표의 `x`, `y`는 게임 바닥이며 `z`는 높이다. Three.js에서는 각각 X, Z, Y축에 대응한다.

## 효과

| 프리셋 | 표현 |
| --- | --- |
| `explosion` | 속성별 입체 파편, 지면 충격파와 섬광. 화염은 불꽃·불티·식어가는 연기. 한 번에 80개 파티클. |
| `slash` | 베는 방향의 부채꼴 궤적에 18개 파편과 불티. 무기의 5프레임 리본 잔상과 함께 표시. |
| `pierce` | 공격 방향으로 좁게 뻗는 16개 불티·파편과 짧은 섬광. |
| `impact` | 맞은 지점에서 솟는 20개 파편·불티, 섬광과 바닥 충격파. |
| `shot` | 진행 방향의 총구 섬광과 12개 불티·파편. 탄착 지점에는 타격 효과. 미니언·건물 사격은 총구 파티클 5개. |

모든 효과는 `THEMES`의 캐릭터별 기존 색상표를 사용한다. 주색 `light`가 파티클·잔광의 기본 색상이고, 강조색 `accent`가 섬광에 섞이며 어두운 보조색 `dark`가 식어가는 파편과 연기에 섞인다. 알리사·료슈의 화염과 참격·관통·타격·사격도 같은 규칙을 따른다. 밝은 주색에서 고유 색상을 거쳐 회색이 섞인 어두운 보조색으로 식는다.

입자는 생성 순간 가장 크고 불투명하다. 수명 비율을 `t`라고 하면 크기는 `초기 크기 × (1−t)^0.8`, 불투명도는 `(1−t)^1.5`다. 수평 속도는 `v₀ × exp(−공기저항 × 경과시간)`으로 감소한다. 수평 위치는 이 속도를 적분해 계산한다. 높이는 `초기 높이 + 초기 수직속도 × 시간 − 중력 × 시간² / 2`로 계산하며 바닥 아래로 내려가지 않는다. 파편의 바닥 그림자는 높이에 따라 흐려진다.

잔광은 바닥 평면을 따라 투영한 가산 합성 레이어다. 주변 챔피언의 스프라이트 알파 영역에 같은 색상의 하이라이트를 합성하고 거리와 시간에 따라 줄인다. 3D 배경을 매 프레임 다시 렌더링하거나 화면 전체 Bloom 후처리를 요구하지 않는다. 체력바와 표식 UI는 파티클 뒤에 가려지지 않도록 마지막에 그린다.

## 참격·관통·타격의 주 이펙트

참격은 여러 겹의 휘어진 검기가 한 궤적으로 이어지며, 양 끝이 가늘어지고 가는 결이 찢어져 흩어진다. 관통은 밀도가 높은 전방 몸체와 긴 중심선, 뒤로 휘감기는 비대칭 가닥으로 구성된다. 사격은 같은 관통 형태의 짧고 좁은 총구 섬광을 사용한다. 타격은 가운데가 빈 거친 충격 고리와 바깥으로 뻗는 가는 방사 파편이다. 주 이펙트는 빠르게 진행한 후 사라진다. 참격·관통·타격 참고 이미지의 형태를 기준으로 직접 그린 흑백 마스크를 캐릭터의 주색으로 착색한다.

파티클은 3단계 밀도 노이즈와 좌표 왜곡으로 만든 불규칙한 윤곽·내부 명암을 사용한다. 서로 다른 네 가지 밀도 형태를 시간에 따라 교차 합성하고, 입자마다 다른 회전·크기·비틀림·전단 변형을 부드럽게 적용한다. 동일한 게임 시각에는 동일한 형태를 표시한다. 수평 속도는 생성 후 0.3초에 80% 이상 줄어든다.

## 속성 표현

| 속성 | 형태 |
| --- | --- |
| 화염 | 솟는 불꽃·불티와 식어가는 연기. 알리사·료슈. |
| 전기 | 가지가 갈라지는 전류, 밝은 중심선, 바닥 방사 전류. 호엔하임. |
| 얼음 | 불규칙한 얼음 조각의 밀도·균열 질감과 서리 안개. 로쟈. |
| 나무 | 길쭉한 목편과 나뭇결, 흔들리는 잎, 바닥 뿌리 가지. 마튼·동랑. |
| 물 | 물방울과 물안개, 낙하 그림자, 바닥의 동심원 파문. 홍루. |
| 꽃·거울·지령 | 동백의 꽃잎, 이상의 거울 결정, 소라·얀·루돌프의 원형 문양. |
| 물리·혈액 | 무기 파편과 불티, 구보의 검붉은 방울. |

전기·얼음·나무·물에는 화염이나 연기 파티클을 생성하지 않는다. 홍루의 물 장판·로쟈의 얼음 장판·동랑의 욕망의 나무·호엔하임의 전류 장판도 생성 시 속성에 맞는 파티클을 표시한다. 전류 파편은 빠르게 뻗고 짧게 사라진다. 얼음과 물은 중력이 강해 빠르게 떨어지며, 목편과 잎은 수평 저항을 크게 받고 가볍게 떨어진다. 잎과 꽃잎은 폭이 흔들리며 회전한다. 속성은 형태와 움직임을 결정하고 색상은 각 캐릭터의 기존 색상표를 따른다.

## 사용 예시

```js
import { SkillVFX } from './src/skill-vfx.js';

const vfx = new SkillVFX();
// 시간은 초, 위치와 반경은 게임의 월드 단위다.
vfx.emit('explosion', { x: 25, y: 38 }, game.time, {
  radius: 4, element: 'fire',
  color: '#ffb67a', accent: '#fbd064', dark: '#a04538',
});
vfx.emit('slash', { x: 25, y: 38 }, game.time, {
  radius: 3, angle: Math.PI / 4, element: 'metal', color: '#90cbff',
});

// 각 프레임: 카메라와 Canvas 크기는 CSS 픽셀 단위다.
vfx.advance(game.time);
vfx.prepare(camera, canvas.clientWidth, canvas.clientHeight);
ctx.save();
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
vfx.drawGround(ctx, camera); // 지면 표시 후, 캐릭터보다 먼저
for (const champion of championsSortedByGroundY) {
  vfx.drawUntil(ctx, champion.y);
  drawChampion(champion);
}
vfx.drawUntil(ctx);         // 남은 전경 파티클
vfx.drawFlashes(ctx, camera);
ctx.restore();
drawHealthBarsAndHud();
```

게임에서는 `sync(game, camera, THEMES)`가 전투 이펙트·투사체·속성 장판의 생성을 관찰해 한 번씩 자동 생성한다. 별도 스윙 이펙트가 없는 기본 공격도 공격 시각을 기준으로 표시한다. 별도 사용 시에는 `emit()`과 `advance()`를 호출하면 된다. `element`는 `fire`, `electric`, `ice`, `wood`, `water`, `petal`, `mirror`, `arcane`, `blood`, `metal`을 사용한다. 카메라는 `worldToScreen({x,y}, height)`, `scale`을 제공해야 한다. 스프라이트 하이라이트는 `lightAt()`과 `tintFrame()`을 이용하며 실제 연결은 [render.js](../src/render.js)의 캐릭터 몸통 그리기에 있다.

파티클은 최대 640개, 잔광 발생 지점은 최대 32개다. 파티클 객체를 풀에서 재사용하며, 화면 밖 발생은 생략한다. 색상별 냉각 스프라이트는 최대 384개, 주 이펙트 착색 마스크는 최대 64개, 캐릭터 틴트는 최대 64개를 캐시한다. 게임의 난수·피해·충돌·쿨타임은 사용하지 않는다. 일시정지 시 물리 운동과 잔광 수명도 멈춘다.
