# 도시 경계 — 오프라인 실행본

Project Moon 작품을 모티브로 한 비공식 팬 게임의 웹 2D 프로토타입입니다.

## 다운로드와 실행

1. 이 폴더의 `city-border-offline.zip`을 엽니다.
2. GitHub 파일 화면의 **Download raw file** 버튼으로 다운로드합니다.
3. ZIP 압축을 풀고 `city-border.html`을 Chrome 또는 Edge로 엽니다.
4. 챔피언을 선택하고 **전장에 진입**을 누릅니다.

설치·서버·인터넷 연결이 필요하지 않습니다. ChatGPT 파일 미리보기 대신 다운로드한 HTML을 일반 브라우저에서 열어 주세요. 비공개 저장소라면 저장소 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.

플레이어 1명 + 봇 7명의 오프라인 4vs4 경기입니다. 파우스트·이상·싱클레어·뫼르소 4명을 플레이할 수 있으며, 기록실에는 31명 원안이 수록되어 있습니다. 온라인 대전과 터치 이동은 미구현입니다.

## 조작

- WASD 이동 / 마우스 조준 / 왼쪽 클릭 공격 / Space 자동 조준
- Q 전술기 / R 궁극기 / 1 회복 물약 / B 상점 / Esc 일시정지

## 파일 검증

외부 요청을 차단한 브라우저에서 로비, 전투 시작, 기술, 상점, 기록실 동작을 확인했습니다. 검증 시 외부 파일 요청 0건, JavaScript 오류 0건이었습니다. ChatGPT 미리보기 서비스 자체의 실행 지원을 보장하는 것은 아닙니다.

ZIP의 SHA-256은 `SHA256SUMS`에서 확인할 수 있습니다.
