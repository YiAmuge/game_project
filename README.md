# 도시 경계 — 4vs4 MOBA v0.28.0

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 플레이어 1명·봇 7명의 AI 대전과 시간 제한 없는 연습장을 지원합니다. 모든 경기는 3D 지형·건물과 평면 챔피언을 사용하는 2.5D로 진행합니다.

전체 효과와 수치는 [현재 구현 규칙](docs/CURRENT_RULES.md) 및 게임 내 도감에 수록합니다.

## ZIP 없이 실행·저장

[개발 브랜치](https://github.com/YiAmuge/game_project/tree/codex/city-border-v0.2)의 Code → Codespaces에서 환경을 엽니다. 초기 설치·서버 시작은 자동 처리합니다. `npm run update`는 현재 브랜치의 코드를 받고 게임 파일과 서버를 확인합니다. 소스 파일은 자동 저장되고 게임 페이지가 새로고침됩니다. 진행 중인 경기는 새로고침 시 초기화됩니다. GitHub 저장은 Commit → Push로 수행합니다.

Ports → 5173 → Open in Browser에서 현재 게임 주소를 엽니다. `npm start`는 서버를 시작·재사용하고, `npm run repair`는 소유권이 확인된 서버를 재시작하며, `npm run doctor`는 게임 파일·서버·외부 응답을 진단합니다. 브라우저 접속 문제는 [실행 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

메뉴: 온라인 대전(준비중), 혼자서 AI와 연습전, 연습장으로 이동, 도감. 일반 선택 챔피언은 29명이며 모제스·에즈라는 도감 실험실에서 사용할 수 있습니다. 도감은 34명을 수록하고 플레이 가능 여부를 표시합니다.

역할군은 챔피언의 플레이 성향입니다. 각 챔피언의 주·부 역할군과 추천 포지션은 선택 화면과 도감에서 확인합니다. 뫼르소는 보호·방해, 추천 포지션은 탑입니다. 추천 포지션과 관계없이 선택할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 | 수동 기본 공격 |
| 우클릭 / Space | 전술기 / 궁극기 |
| 좌클릭 / 우클릭·Esc | 좌표 지정 기술 확정 / 취소 |
| Tab 유지 | 확대 지도·KDA·성장 수치·크립 타이머 |
| G / B | 상점 / 3초 귀환 |
| F12 / 화면의 ⛶ 버튼 | 전체 화면 |

얀·호엔하임 기본 공격과 히스클리프 전술기는 누른 채 충전하고 놓아서 사용합니다. 모제스·에즈라 전술기는 우클릭 드래그 방향으로 선택합니다. 하단에는 패시브와 기본 공격·전술기·궁극기 칸이 표시되며, 패시브에 대기시간이 있으면 남은 시간을 표시합니다. 체력·탄창·정신력·충전량은 챔피언 머리 위에, 보호막은 체력바 안에 표시합니다.

## 전장과 연습장

전장은 본진·상하단 라인·정글·외곽 캠프로 구성됩니다. 첫 미니언은 3초에 출격하며 웨이브 간격은 25초입니다. 포탑 체력 5168, 본진 체력 8160. 20분 제한, 본진 파괴 시 즉시 승리합니다. 포탑 하나를 잃으면 본진이 공격 가능해집니다. 체력 35% 미만 본진은 10초 비피격 후 최대 체력 15% 보호막을 얻습니다.

연습장은 회복·피해, 크립, 대치 허수아비, 이동 표적, 미니언·포탑의 다섯 구역으로 구성됩니다. 시간 제한 없이 어디서나 무료 상점을 사용하며, 우측 상단의 접을 수 있는 옵션에서 무적·쿨다운·탄창·소환·AI·챔피언 변경·지도 이동 등을 조절합니다. 무한 허수아비 위에서 피해량·치유량을 확인합니다.

증강은 최대 4개, 각 카테고리 최대 2개를 보유합니다. 전투력·체력 업그레이드는 각 5단계, 이동속도·장전속도·가속은 각 3단계입니다. 증강 12종의 효과·조건과 모든 챔피언 기술은 [현재 구현 규칙](docs/CURRENT_RULES.md)에 상세하게 설명합니다.

## 렌더링과 검증

일반 피격은 몸통에 붙는 흰색·회색 파편과 짧은 스파크로 표현합니다. 공격은 실제 반경·폭·방향 안에 표시하며, 파편은 높이 방향의 포물선 운동과 수평 감속·축소·투명도 감소를 사용합니다. 탄환·나이프·못·작살·거울 조각·얼음도끼는 재질과 궤적을 가진 별도 투사체로 표시합니다. 물·전류·얼음·나무·불꽃은 지정된 기술의 속성에 맞춰 표현합니다. 버프·보호막은 은은한 오라를 사용하고, 잔광과 몸통 하이라이트는 겹쳐서 과도하게 밝아지지 않도록 제한합니다. [챔피언별 시각 표현](docs/COMBAT_VISUAL_GUIDE.md)과 [이펙트 코드](docs/SKILL_VFX.md)에 자세히 설명합니다.

휘두르기·베기 공격은 무기별 최대 5프레임의 실제 위치를 연결하는 잔상을 표시합니다. 오래된 위치일수록 꼬리가 가늘고 투명하며, 무기 모션이 끝나면 0.12초 동안 사라집니다. 무기와 베기 이펙트의 색상을 사용하며 카메라 이동·창 크기 변경·일시정지에도 공격 위치를 따라 표시합니다.

벽·포탑이 챔피언을 가리면 반투명해집니다. 캐릭터와 몸통 표식·체력 UI는 지면 좌표에서 투영한 평면으로 표시하고, 공격 범위·장판은 지면에, 투사체는 높이가 있는 비행 궤적으로 표시합니다. 3D 배경은 여유 영역을 포함해 캐시하며 카메라 이동·가림 상태·건물 파괴에 맞춰 갱신합니다. 3D 화면의 해상도 예산은 921600픽셀입니다. Three.js는 로컬 번들로 포함합니다. WebGL 지원 브라우저가 필요합니다.

```sh
npm ci
npm run check
npm test
npm run build
PORT=5180 npm start
MOBA_TEST_URL=http://127.0.0.1:5180 python tests/v25_browser.py
```

`npm run build`는 외부 파일 없이 열리는 `dist/city-border.html`과 `dist/index.html`을 생성합니다. `node scripts/sync-content.mjs`는 도감의 기술 설명으로 툴팁·규칙 문서를 생성합니다. Three.js 의존성 갱신 후 `npm run vendor`로 로컬 번들을 생성합니다.
