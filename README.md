# 도시 경계 — 4vs4 MOBA v0.24.0

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 첨부 기획서와 이후 변경 요청을 기준으로 플레이어1명·봇7명의 웹 연습전을 개발합니다.

## ZIP 없이 수정·실행

[개발 브랜치](https://github.com/YiAmuge/game_project/tree/codex/city-border-v0.2)의 **Code → Codespaces → 새 Codespace**로 시작합니다. 초기 설치·서버 시작을 자동 처리합니다. 기존 환경은 `npm run update`로 현재 브랜치의 변경을 받고 서버를 확인합니다. 로컬 수정과 충돌하면 덮어쓰지 않고 실패를 알립니다.

**Ports → 5173 → Open in Browser**로 현재 주소를 엽니다. 소스는800ms 후 자동 저장되고 게임은 약1.2초 후 새로고침됩니다. GitHub 저장은 별도로 **Commit → Push**합니다. 새로고침은 진행 중 경기를 초기화합니다.

`npm start` 시작·재사용, `npm run repair` 소유권이 확인된 서버 재시작, `npm run doctor` 실제 게임 파일·외부 응답 진단을 지원합니다. 내부 HTTP200이나 터미널의 외부 응답만으로 사용자의 브라우저 접속 성공을 뜻하지 않습니다. Codespaces 외부404가 남으면 [실행 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

메뉴는 온라인 대전(준비중), AI 연습전, 연습장으로 이동, **연습장 (2.5D)**, 도감입니다. 탑·정글·바텀·서포터와 챔피언을 선택합니다. 추천 역할군은 선택을 제한하지 않습니다.

일반 선택 **29명**: 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르, 구보, 가환, 넬리, 에이해브, 루돌프, 묘, 동백, 동랑, 호엔하임, 알리사, 마튼, 퀴케그, 스타벅, **김삿갓, 뿌이**, **소라, 얀**. 모제스·에즈라는 실험실에서 선택하며 도감에는34명의 기획을 수록합니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 | 수동 기본 공격 |

히스클리프는 우클릭을 누른 채 충전 후 놓아서 도약, 루돌프 궁극기는 확대 지도 확정, 모제스·에즈라는 우클릭 드래그 선택입니다. 구보는 붉은 표적의 아군에게 일반 좌클릭 또는 커서 조준 후 Space로 공격합니다.

## v0.24 2.5D 성능과 스프라이트 배치 수정

챔피언·미니언·크립·허수아비를 매 프레임 CanvasTexture로 복사하던 처리를 없애고, 지면에 투영한 발 좌표를 기준으로 2D 캔버스에 직접 그립니다. 몸통·다리·무기가 바닥/벽과 교차해 잘리던 현상을 수정했습니다. 그림자와 공격 범위는 지면에, 체력바와 탄창은 개체 위에 표시합니다. 벽·포탑의 반투명 가림 처리는 유지합니다.

고정된 바닥 표시는 한 번 그려 캐시하고, 스킬 이펙트·투사체는 지면의 투영 행렬로 직접 표시합니다. 3D 배경은 카메라 이동용 여유 영역을 포함해 캐시하여 이동 중에는 화면을 평행 이동하고, 여유 영역 소진·벽 투명도 변경·포탑 파괴·창 크기 변경 시에 다시 그립니다. 3D 해상도에 약92만 픽셀 예산과 가벼운 조명을 적용하며, 캐릭터와 UI의 선명도는 유지합니다.

검증 환경(Chromium 소프트웨어 렌더러·1440×900)에서 추가 챔피언20명의 정지 장면은 약4.3fps에서60fps로 개선됐고, 이동 시험은 약54fps였습니다. 준비 완료 후 정지·이동 시험 모두 개체/효과 텍스처의 반복 업로드는0회였습니다. 실제 프레임은 기기와 전투 상황에 따라 달라집니다. `tests/v24_browser.py`는 FPS의 고정 기준 대신 전송 횟수, 배경 재사용/갱신, 벽 네 면에서의 몸통 픽셀 보존과 발 위치를 검사합니다.

## v0.23 독립된 2.5D 연습장

메뉴 **연습장 (2.5D)**에서 챔피언을 선택하면 기존 연습장과 다른 `입체 실험 정원`에 입장합니다. 3D 바닥·벽·포탑 위에 기존 2D 챔피언과 커서 조준 무기를 배치했습니다. 카메라는 캐릭터를 따라 비스듬히 내려다보며, 공격 범위와 판정은 동일한 지면 좌표를 사용합니다. 벽·포탑이 챔피언을 가리면 실제 3D 시선 판정으로 해당 오브젝트를 반투명하게 표시합니다. 체력바·탄창·측정치는 화면 위에 표시합니다.

기존 다섯 실험 구역과 무료 상점, 옵션, 챔피언 소환/제거/변경, 시간 제한 없는 연습을 모두 지원합니다. 기존 2D 연습장과 AI 대전의 맵 및 시점은 유지됩니다. 2.5D 모드는 WebGL 지원이 필요하며, 지원하지 않는 환경에서는 입장 안내를 표시합니다. Three.js는 로컬 번들로 포함해 CDN 없이 실행하며 단일 HTML 빌드에도 포함됩니다. 의존성 갱신 시 `npm run vendor`로 로컬 번들을 재생성합니다.

## v0.22 판정·이펙트와 연습장 측정

이스마엘 작살은0.235초 조준 후 속도28·사거리16으로 날아가 첫 적 챔피언 한 명만 끕니다. 오티스 후속 부채꼴은 돌진 방향을 향하며 뫼르소 기본 공격은2.6×2.6 직선, 궁극기는사거리8·0.275초에 걸쳐 해소되는99% 이동 제한입니다. 뿌이의 강화 아군 연계 공격을 제거하고 아군 강화 재부여에2.5초 제한을 적용했습니다.

연습장 **소환한 챔피언 제거**에서 전체 또는 소환 순서 번호로 한 명을 제거합니다. 처치 보상·사망 패시브는 발동하지 않습니다. 피해 장판은초당최대HP3.3%입니다. 무한 허수아비 위에는 최근1초 피해/치유, 총량, 마지막 공격/치유기 수치를 표시합니다. 아군 무한 허수아비는 체력이 가득 차도 실제 회복량을 받고 측정하며, 같은 지속 치유 기술의 회복은 마지막 치유기 합계로 묶습니다.

## v0.21 챔피언 전투와 연습장 소환

히스클리프 전술기는 누르고 놓아 도약합니다. 얀의 전술기 종료 후 완충 공격, 돈키호테·퀴케그 직선 공격, 파우스트 성장·반원 밀치기·궁극기 강화, 구보 전방 관통·처형 마법진·즉발 레이저, 이스마엘·그레고르 고속 끌기를 반영했습니다. 오티스 궁극기는 충돌 돌진·후퇴와 뒤쪽 부채꼴 후속 공격으로 변경했습니다. 마튼은 나무 망치 근접/원거리 공격을 사용하며, 홍루는 통찰 이동과 전진/정지 가능한 궁극기를 사용합니다. 호엔하임 장판은 추적 대상 사망 시 정지하고 수동 재지정을 기다립니다.

연습장 우측 상단 **챔피언 소환**에서 선택 → 아군/적군 → 지도 위치로 배치합니다. 같은 챔피언을 여러 번 소환할 수 있으며 사망 중에도 이용합니다. **소환한 챔피언 AI**는 기본적으로 꺼져 있고, 켜면 소환 챔피언 전체가 전투합니다. 기존 허수아비의 동작과 플레이어 전용 연습 옵션은 별도로 유지합니다.

퀴케그·스타벅·이스마엘은 아군 에이해브의 명령 반경에 3초 머물면 각 대사를 2초 표시합니다. 같은 팀의 같은 챔피언 대사는 게임당 한 번입니다. 이번 수치와 미지정 세부값은 [구현 규칙](docs/PROTOTYPE.md)에 기록했습니다.

## v0.20 호엔하임과 에이해브

호엔하임은 탄창 대신 좌클릭 유지로 전류를 충전하고 놓으면 발사합니다. 기본1.5초 충전, 피해100→150·사거리6→9·1→3타(30%·60%에서 추가 타격)이며 충전 중 이동−20%입니다. 장전 성능은 충전을 가속하고 추가 탄창1개는 피해+5%·사거리+0.75로 전환합니다. 발사 간격은 최소0.65초이며 사후2.5초 동안은 충전 없이 완충3타를 발사합니다.

궁극기는7초·0.4초당20피해로 적 챔피언을 추적합니다. 유지 중 Space→적 좌클릭으로 추적 대상을 변경하며 지속시간·기본 쿨다운을 다시 시작하지 않습니다. 미지정 추적 속도는초당6, 장판 반경4.2·초기 시전 거리8은 유지합니다.

에이해브 두 전술기 명령의 버프 반경은8입니다. 실제 발동·피해 전가 후보·원형 표시·도감 설명에 같은 범위를 적용합니다.

- 지령은 소라의 첫 공격 적중으로 소모됩니다. 피해 20% 조건을 제거했으며 해금·기본 상태 탄창 회복은 유지합니다. 대상 몸통의 파란 꽃은 참고 이미지를 복제하지 않은 별도의 6꽃잎 Canvas 이펙트입니다.

- 일반 전술기는 기존 첫 충돌 판정·보호막을 유지하고 충격파와 잠시 남는 지면 균열을 표시합니다.

## 개발·검증

Node.js22 이상, 빌드에는 잠금 파일의 esbuild를 사용합니다.

```bash
npm ci
npm start
npm run check
npm test
npm run build
```

브라우저 시험은 실행 중 서버와 Python Playwright·Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로·서버를 지정합니다.

```bash
python3 tests/browser_smoke.py
python3 tests/sora_browser.py
python3 tests/v14_browser.py
python3 tests/training_browser.py
python3 tests/training25d_browser.py
python3 tests/v24_browser.py
python3 tests/standalone_smoke.py
```

`npm test`는 전투·충돌·규칙·실행 도구와29명 각각60초, 대표4포지션10분 경기 시뮬레이션을 포함합니다. 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. `dist/index.html`과 `dist/city-border.html`은 코드·스타일·도감·스프라이트9장·3D 엔진을 내장한 동일한 HTML입니다.

주요 파일은 규칙`src/data.js`, 전투`src/game.js`, 기술`src/skills.js`와각 버전 챔피언 모듈, 처치·현상금·알림`src/combat-events.js`, 충돌`src/collision.js`, 상점`src/main.js`, 외형`src/art.js`·`src/render.js`입니다. 온라인·일반 전장의 안개·터치 이동·사운드·경기 저장은 아직 없습니다. 이미지에는 생성 팬아트를 사용하며 원작 세부 검수 한계가 있습니다.

Pages 게시 절차는 [개발 안내](docs/LIVE_DEVELOPMENT.md)에 있습니다. 개발 브랜치 푸시와 공개 배포는 별도입니다.
