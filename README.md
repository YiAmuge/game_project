# 도시 경계 — 4vs4 MOBA v0.5

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 첨부 기획서 두 종과 이후 사용자의 변경 요청을 기준으로 개발합니다. PC 브라우저에서 플레이어 1명과 봇 7명이 싸웁니다.

## ZIP 없이 수정하고 실행하기

GitHub **`codex/city-border-v0.2` 브랜치**의 **Code → Codespaces → Create codespace on this branch**로 시작하세요. 브랜치 이름은 유지하며 현재 소스는 v0.5입니다. 기존 Codespace에서는 작업 내용을 Commit한 뒤 **Source Control → Pull**로 최신 코드를 받습니다.

**Ports → 5173 → Open in Browser**로 게임을 엽니다. 파일은 800ms 후 자동 저장되고 약 1.2초 후 게임이 새로고침됩니다. 새로고침하면 경기는 초기화됩니다. GitHub에도 변경을 보관하려면 **Commit → Sync Changes / Push**가 필요합니다. [상세 개발 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

입장 메뉴는 온라인 대전(준비중), AI 연습전, 도감입니다. 연습전에서 탑·정글·바텀·서포터와 챔피언을 선택합니다. 추천 역할군은 선택을 제한하지 않습니다.

**일반 챔피언 16명:** 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르, **구보, 가환, 넬리, 에이해브**. 도감에는 전체 31명의 기획을 수록합니다. 루돌프·모제스·에즈라·알리사 4명은 도감의 조작·규칙 실험실에서 플레이할 수 있으며 임시 몸체를 사용합니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 유지 | 수동 기본 공격 |
| 우클릭 / Space | 전술기 / 궁극기 준비 → 범위 확인 → **좌클릭 확정** |
| 우클릭 / Esc | 준비 중 스킬 취소, 미시전 쿨타임·자원 보존 |
| Tab 유지 | 확대 지도, 8명 KDA·레벨·성장 수치, 크립 타이머 |
| G / 1 | 상점 / 물약 |
| B | 3초 귀환. 피격·이동·공격·기술·강한 CC·재입력으로 취소 |
| F12 | 전체 화면. 브라우저가 키를 선점하면 화면의 ⛶ 버튼 사용 |
| Esc | 취소 또는 일시정지 |

이동·돌진기는 빠른 시전을 유지합니다. 좌표 지정 궁극기인 료슈·싱클레어·넬리는 조준 후 클릭 확정합니다. 히스클리프는 우클릭 충전 후 **좌클릭 발사**. 루돌프 궁극기는 확대 지도에서 클릭 확정. 모제스·에즈라는 우클릭 드래그로 방향을 고른 뒤 좌클릭 확정하며 드래그 없이 놓으면 취소됩니다. 구보의 아군 공격은 **Ctrl+좌클릭**, 아군 궁극기 지정은 **Ctrl+Space 후 좌클릭**이며 체력 17% 이하 아군에게만 허용합니다.

## 전투·성장·상점

- 베기 무기는 좌우로 번갈아 휘두르고 찌르기·사격과 구분합니다. 검기, 피격 섬광·파편, 사망 위치의 시체를 표시합니다. 체력 숫자·탄창·정신력·중첩은 챔피언 머리 위에 표시합니다.
- 기본 공격의 탄창 소모 간격은 30% 증가하며 기존 고속 공격(0.4초 이하)은 유지합니다. **공격 중에는 장전이 멈추고 기존 부분 진행도는 보존**됩니다. 공통 장전 계수 0.52는 그대로입니다.
- 3초 비공격·비피격 후 초당 최대 체력 13% 자연 치유. 알리사 열화 자해는 비치명적이며 치유 대기에서 제외됩니다.
- 챔피언별 전투력·체력·이동속도가 레벨마다 증가하며 최대 10레벨입니다. 미니언 처치 시 근처 아군이 있으면 처치자가 80%, 아군이 합계 20%를 나누어 받습니다.
- 전투력·체력 강화는 **5단계**, 이동·장전·가속은 **3단계**. 가격은 단계별 160/260/400/580/800. 살아 있으면 부활소의 3초 비전투 상태, **사망 중에는 위치와 무관하게 강화·증강 구매 가능**. 물약은 살아서 부활소에 있을 때만 구매합니다.
- 증강 12종 중 최대 3개를 장착합니다. 전투 강화 3단계 / 체력 강화 3단계 / 이동·장전·가속 합계 3단계가 각 범주의 선택 조건입니다. 임시 가격은 구매 500, 판매 350 재화이며 교체할 수 있습니다. 쿨타임·최대 탄창·사거리·교전/생존 발동 효과를 실제 전투에 적용합니다.

돈키호테 전술기는 방향 고정 2.5초 찌르기·이동 허용·정면 피해 감소로 변경했습니다. 파우스트 10레벨 탄창·사거리 패시브, 로쟈 기본 돌진·전술기 9초, 이상 장판의 짧은 연속 침묵·장전 약화, 히스클리프 궁극기 반경 7.5, 오티스 궁극기 사거리 18, 이스마엘 관통 작살 사거리 16을 반영합니다.

맵은 **83.2×46.8**이며 유닛과 카메라 크기는 유지합니다. 본진 뒤 **반월형 부활소**를 분리하고 귀환·부활·상점·회복·적 침입 피해가 같은 경계를 사용합니다. 첫 미니언은 **0초**, 이후 25초마다 출격합니다. 미니언은 2분마다 체력 6%·공격력 5% 성장, 12분에 종료합니다. 포탑 피해 감소는 근접 30%·원거리 20%·공성 50%입니다. 원거리 미니언·포탑은 이동하는 유도 투사체로 공격합니다.

크립은 피격 전 선공하지 않습니다. 적대 중 캠프 반경 3.4 밖에 **1.85초** 머물면 적대를 해제하고 빠르게 복귀합니다. 복귀 중 피해·CC를 무시하고 회복합니다. 재생성 시간은 전장과 지도에 표시합니다. 5분에 중앙 보스가 등장합니다. **시간제한 없이 적 포탑 2개와 본진을 파괴해야 승리**합니다.

## 개발·검증

Node.js 22 이상:

```bash
npm ci
npm run dev
```

기본 포트는 5173이며 `PORT=8080 npm run dev`로 변경할 수 있습니다. Codespaces 재연결 시 `node scripts/codespaces-start.mjs`가 서버를 재사용합니다.

```bash
npm run check
npm test
npm run build
python3 tests/browser_smoke.py
python3 tests/v04_browser.py
python3 tests/v05_browser.py
python3 tests/standalone_smoke.py
```

브라우저 검증에는 Python Playwright와 Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로·서버를 변경합니다. `?debug=1`로 테스트 상태를 열며 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. 규칙 테스트는 16명 각각의 60초 경기와 대표 4개 포지션의 10분 경기, 증강 발동·가격·재판매, 새 챔피언과 변경 규칙을 검사합니다.

`dist/index.html`과 `dist/city-border.html`은 코드·스타일·도감·**세 스프라이트 아틀라스**를 내장한 동일한 실행본입니다. 외부 요청을 차단한 sandbox iframe에서도 검사합니다. 실제 ChatGPT 미리보기에서 스크립트 실행을 허용한다는 뜻은 아닙니다.

| 파일 | 역할 |
| --- | --- |
| `src/data.js`, `src/extra-data.js`, `src/new-data.js` | 규칙·지형·챔피언 능력치·성장치 |
| `src/game.js` | 전투·경제·성장·치유·AI·투사체 |
| `src/skills.js`, `src/new-champions.js` | 기술·패시브·다단 타격 |
| `src/augments.js` | 증강 조건·가격·중첩·발동 |
| `src/targeting.js` | 시전 범위·좌표 제한·조준 미리보기 |
| `src/render.js`, `src/overlays.js`, `src/art.js`, `src/camera.js` | 시점·무기·효과·시체·체력 UI |
| `src/main.js`, `src/style.css`, `index.html` | 입력·메뉴·상점·도감 |
| `docs/PROTOTYPE.md`, `docs/ART_DIRECTION.md` | 구현 수치·미정 값·그림 기준과 검증 한계 |

온라인 대전·일반 전장의 안개·터치 이동·사운드·경기 저장은 아직 없습니다. 그림은 생성한 팬아트이며 특히 신규 N사 E.G.O. 의상의 원작 세부 일치 여부는 추가 시각 검수가 필요합니다.

Pages 게시 절차는 [개발 안내](docs/LIVE_DEVELOPMENT.md)에 있습니다. 개발 브랜치 업데이트와 공개 배포는 별도입니다.
