# 도시 경계 — 4vs4 MOBA v0.11.0

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 첨부 기획서와 이후 변경 요청을 기준으로 플레이어1명·봇7명의 웹 연습전을 개발합니다.

## ZIP 없이 수정·실행

[개발 브랜치](https://github.com/YiAmuge/game_project/tree/codex/city-border-v0.2)의 **Code → Codespaces → 새 Codespace**로 시작합니다. 초기 설치·서버 시작을 자동 처리합니다. 기존 환경은 `npm run update`로 현재 브랜치의 변경을 받고 서버를 확인합니다. 로컬 수정과 충돌하면 덮어쓰지 않고 실패를 알립니다.

**Ports → 5173 → Open in Browser**로 현재 주소를 엽니다. 소스는800ms 후 자동 저장되고 게임은 약1.2초 후 새로고침됩니다. GitHub 저장은 별도로 **Commit → Push**합니다. 새로고침은 진행 중 경기를 초기화합니다.

`npm start` 시작·재사용, `npm run repair` 소유권이 확인된 서버 재시작, `npm run doctor` 실제 게임 파일·외부 응답 진단을 지원합니다. 내부 HTTP200이나 터미널의 외부 응답만으로 사용자의 브라우저 접속 성공을 뜻하지 않습니다. Codespaces 외부404가 남으면 [실행 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

메뉴는 온라인 대전(준비중), AI 연습전, 도감입니다. 탑·정글·바텀·서포터와 챔피언을 선택합니다. 추천 역할군은 선택을 제한하지 않습니다.

일반 선택 **25명**: 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르, 구보, 가환, 넬리, 에이해브, 루돌프, 묘, 동백, 동랑, 호엔하임, 알리사, 마튼, 퀴케그, **스타벅**. 모제스·에즈라는 실험실에서 선택하며 도감에는32명의 기획을 수록합니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 | 수동 기본 공격 |
| 우클릭 / Space | 전술기 / 궁극기 |
| 좌클릭 / 우클릭·Esc | 좌표 지정 기술 확정 / 취소 |
| Tab 유지 | 확대 지도·8명 KDA·성장 수치·크립 타이머 |
| G / B | 상점 / 3초 귀환 |
| F12 | 전체 화면; 브라우저가 선점하면 화면의 ⛶ 버튼 |

히스클리프는 우클릭 충전 후 좌클릭 발사, 루돌프 궁극기는 확대 지도 확정, 모제스·에즈라는 우클릭 드래그 선택입니다. 구보는 붉은 표적의 아군에게 일반 좌클릭 또는 커서 조준 후 Space로 공격합니다.

## v0.11 변경

- 포탑·크립·미니언 등에 사망해도 마지막 적 챔피언 피해가 10초 이내면 해당 챔피언에게 처치를 귀속합니다. 10초를 넘으면 처형입니다. 보호막 피해도 포함합니다.
- 선취점에서 처치자와 어시스트의 재화 보상을 각각 1/3 늘립니다. 죽지 않고 3킬부터 현상금 +60, 이후 킬마다 +40, 최대 +220입니다. 사망하면 초기화합니다.
- 상단에 처치·2연킬·3연킬·올킬, 선취점·현상금 회수, 포탑 파괴·보스 등장·처치 알림을 표시합니다. 빠른 연속 처치는 기존 메시지를 갱신하며 클릭을 가리지 않습니다.
- 스타벅 만탄 전진 2.875, 전술기 좌우 범위 +120%·반복 간격 0.33초. 에이해브 3탄창·방어 명령 중 이동/방어 +12%·궁극기 사거리 6.5.
- 퀴케그는 무기한 연결하며 양쪽 방어 효율 +10%, 대상이 군중제어 중이면 받는 피해 50%를 대신 받습니다. 이상 패시브 보호막은 유지 중 대상에게 초당 `7 + 대상 최대 HP의 1.5%`를 회복합니다.

자세한 실제 수치와 미지정 값의 선택은 [개발 명세](docs/PROTOTYPE.md), 외형 제작 기준은 [그림 명세](docs/ART_DIRECTION.md)에 기록했습니다.

## 개발·검증

Node.js22 이상, 빌드에는 잠금 파일의 esbuild를 사용합니다.

```bash
npm ci
npm start
npm run check
npm test
npm run build
```

브라우저 시험은 실행 중 서버와 Python Playwright·Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로·서버를 지정합니다.

```bash
python3 tests/browser_smoke.py
python3 tests/v11_browser.py
python3 tests/standalone_smoke.py
```

`npm test`는 전투·충돌·규칙·실행 도구와25명 각각60초, 대표4포지션10분 경기 시뮬레이션을 포함합니다. 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. `dist/index.html`과 `dist/city-border.html`은 코드·스타일·도감·스프라이트6장을 내장한 동일한 HTML입니다.

주요 파일은 규칙`src/data.js`, 전투`src/game.js`, 기술`src/skills.js`와각 버전 챔피언 모듈, 처치·현상금·알림`src/combat-events.js`, 충돌`src/collision.js`, 상점`src/main.js`, 외형`src/art.js`·`src/render.js`입니다. 온라인·일반 전장의 안개·터치 이동·사운드·경기 저장은 아직 없습니다. 이미지에는 생성 팬아트를 사용하며 원작 세부 검수 한계가 있습니다.

Pages 게시 절차는 [개발 안내](docs/LIVE_DEVELOPMENT.md)에 있습니다. 개발 브랜치 푸시와 공개 배포는 별도입니다.
