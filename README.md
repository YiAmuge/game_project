# 도시 경계 — 4vs4 MOBA v0.14.0

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 첨부 기획서와 이후 변경 요청을 기준으로 플레이어1명·봇7명의 웹 연습전을 개발합니다.

## ZIP 없이 수정·실행

[개발 브랜치](https://github.com/YiAmuge/game_project/tree/codex/city-border-v0.2)의 **Code → Codespaces → 새 Codespace**로 시작합니다. 초기 설치·서버 시작을 자동 처리합니다. 기존 환경은 `npm run update`로 현재 브랜치의 변경을 받고 서버를 확인합니다. 로컬 수정과 충돌하면 덮어쓰지 않고 실패를 알립니다.

**Ports → 5173 → Open in Browser**로 현재 주소를 엽니다. 소스는800ms 후 자동 저장되고 게임은 약1.2초 후 새로고침됩니다. GitHub 저장은 별도로 **Commit → Push**합니다. 새로고침은 진행 중 경기를 초기화합니다.

`npm start` 시작·재사용, `npm run repair` 소유권이 확인된 서버 재시작, `npm run doctor` 실제 게임 파일·외부 응답 진단을 지원합니다. 내부 HTTP200이나 터미널의 외부 응답만으로 사용자의 브라우저 접속 성공을 뜻하지 않습니다. Codespaces 외부404가 남으면 [실행 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

메뉴는 온라인 대전(준비중), AI 연습전, 도감입니다. 탑·정글·바텀·서포터와 챔피언을 선택합니다. 추천 역할군은 선택을 제한하지 않습니다.

일반 선택 **28명**: 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르, 구보, 가환, 넬리, 에이해브, 루돌프, 묘, 동백, 동랑, 호엔하임, 알리사, 마튼, 퀴케그, 스타벅, **김삿갓, 뿌이**, **소라**. 모제스·에즈라는 실험실에서 선택하며 도감에는33명의 기획을 수록합니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 | 수동 기본 공격 |
| 우클릭 / Space | 전술기 / 궁극기 |
| 좌클릭 / 우클릭·Esc | 좌표 지정 기술 확정 / 취소 |
| Tab 유지 | 확대 지도·8명 KDA·성장 수치·크립 타이머 |
| G / B | 상점 / 3초 귀환 |
| F12 | 전체 화면; 브라우저가 선점하면 화면의 ⛶ 버튼 |

히스클리프는 우클릭 충전 후 좌클릭 발사, 루돌프 궁극기는 확대 지도 확정, 모제스·에즈라는 우클릭 드래그 선택입니다. 구보는 붉은 표적의 아군에게 일반 좌클릭 또는 커서 조준 후 Space로 공격합니다.

## v0.14 조정

- 소라: 해금5·변신20초. **머리 으깨기만 범위+120%**, 변신 평타 반경2.7 유지. 일반Q사거리7·판정폭+70%, 변신Q사거리6.5. 두 상태를 큰 머리·짧은 몸의2등신으로 보정하고 둥근 안경을 유지했습니다.
- 김삿갓: 기본범위+30%·후속넓은베기추가+20%. Q는 최대1.8초 기절·이동하며 검으로 끌기, 재사용으로 해제/밀치기. 두 몸체의 충돌을 함께 검사하며 사슬을 사용하지 않습니다. 몸체·초상·시체를 좌우 반전했습니다.
- 뿌이: 미니언공유XP에도패시브+15%, 기본사거리7·초당150+현재잃은HP2.5%회복. Q는범위내모든아군에게적용. R은이동가능·총720피해·사용즉시탄창완충과Q초기화입니다.
- 돈키호테: Q조기취소는유지하며쿨다운반환을제거했습니다. 도감과스킬설명도같은규칙을표시합니다.

## v0.13 소라

- 암살 챔피언 소라와 조건부 궁극기 **개화 E.G.O::대행**을 추가했습니다. 3초 주기 지령·20% 피해 해금·5스택 변신·20초 후 일반 상태 복귀를 구현했습니다.
- 일반/변신 모두 첨부 외형을 바탕으로 한 팔 없는2등신 반측면이며, 요청한 **동그란 렌즈의 안경**을 유지합니다. 구속된 양손과 거대한 검은 양팔은 커서를 따라 움직이는 별도 무기입니다.
- 일반 Q는 좌표 확정 돌진·첫 충돌 기절·지령 대상 장전, 변신 Q는 무적 돌진·실제 경로에6회 베기·감속 갱신입니다. 변신 중 기본 공격은360도 원형 공격이며 공격 중 장전이 계속됩니다.
- 해금/지령 피해 진행도·변신 남은 시간을 전장에 표시하고 기본/Q/R 이름과 초상화·시체도 상태에 맞춥니다. 도감에 원안과 미지정 수치의 선택을 기록했습니다.

## v0.12 변경

- 자동 경험치를 초당3으로 조정했습니다. 김삿갓·뿌이를 일반 선택과 봇 후보에 추가했습니다.
- 김삿갓은 검 붙잡기·재사용 밀치기와 피격 반격 검파를, 뿌이는 아군 회복·150피해의 못 지원·지면 정화·못 폭풍을 사용합니다. 첨부 외형을 반영했고 뿌이는 최종 요청에 따라45도 반측면으로 서 있습니다.
- 스타벅은 매 기본 공격 돌진, 강화된 범위·피해, 0.3초 연속 찌르기·구속을 사용합니다. 궁극기는 적중 여부와 무관하게 전술기·탄창을 초기화하며, 적중한 적1명을 원 안에 포획합니다.
- 퀴케그 패시브를 현재 잃은 체력에 따라 실시간 계산합니다. 돈키호테는 전술기 조기 취소(쿨다운 반환 없음), 좌표 지정 논타겟 궁극기·7초 흡혈을 사용합니다.
- 이상 기본 파편을 확대·관통으로 바꾸고 장판의 첫 탄창 소모·누적 감속을 추가했습니다. 묘는 전술기65피해, 궁극기4.5초·기본 돌진 중 피해50%감소를 적용했습니다.
- 도감의 ‘부활소 증강’에서12종의 효과·가격·해금 조건과 판매 규칙을 확인할 수 있습니다.

자세한 실제 수치와 미지정 값의 선택은 [개발 명세](docs/PROTOTYPE.md), 외형 제작 기준은 [그림 명세](docs/ART_DIRECTION.md)에 기록했습니다.

## 개발·검증

Node.js22 이상, 빌드에는 잠금 파일의 esbuild를 사용합니다.

```bash
npm ci
npm start
npm run check
npm test
npm run build
```

브라우저 시험은 실행 중 서버와 Python Playwright·Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로·서버를 지정합니다.

```bash
python3 tests/browser_smoke.py
python3 tests/sora_browser.py
python3 tests/v14_browser.py
python3 tests/standalone_smoke.py
```

`npm test`는 전투·충돌·규칙·실행 도구와28명 각각60초, 대표4포지션10분 경기 시뮬레이션을 포함합니다. 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. `dist/index.html`과 `dist/city-border.html`은 코드·스타일·도감·스프라이트8장을 내장한 동일한 HTML입니다.

주요 파일은 규칙`src/data.js`, 전투`src/game.js`, 기술`src/skills.js`와각 버전 챔피언 모듈, 처치·현상금·알림`src/combat-events.js`, 충돌`src/collision.js`, 상점`src/main.js`, 외형`src/art.js`·`src/render.js`입니다. 온라인·일반 전장의 안개·터치 이동·사운드·경기 저장은 아직 없습니다. 이미지에는 생성 팬아트를 사용하며 원작 세부 검수 한계가 있습니다.

Pages 게시 절차는 [개발 안내](docs/LIVE_DEVELOPMENT.md)에 있습니다. 개발 브랜치 푸시와 공개 배포는 별도입니다.
