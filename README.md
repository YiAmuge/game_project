# 도시 경계 — 4vs4 MOBA v0.7

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 첨부 기획서 두 종과 이후 사용자의 변경 요청을 기준으로 개발합니다. PC 브라우저에서 플레이어 1명과 봇 7명이 싸웁니다.

## ZIP 없이 수정하고 실행하기

GitHub **`codex/city-border-v0.2` 브랜치**의 **Code → Codespaces → Create codespace on this branch**로 시작하세요. 브랜치 이름은 유지하며 현재 소스는 v0.7입니다. 기존 Codespace에서는 작업 내용을 Commit한 뒤 **Source Control → Pull**로 최신 코드를 받습니다.

**Ports → 5173 → Open in Browser**로 게임을 엽니다. 파일은 800ms 후 자동 저장되고 약 1.2초 후 게임이 새로고침됩니다. 새로고침하면 경기는 초기화됩니다. GitHub에도 변경을 보관하려면 **Commit → Sync Changes / Push**가 필요합니다. [상세 개발 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

껐다 켠 뒤 `app.github.dev` 주소에서 404가 나오면 먼저 기존 Codespace를 열고, 터미널에서 `node scripts/codespaces-start.mjs`를 실행한 다음 Ports의 5173을 다시 여세요. 이 주소는 Codespace가 켜져 있을 때 사용하는 개발 주소입니다. [재시작·404 복구 안내](docs/LIVE_DEVELOPMENT.md#껐다-켠-뒤-게임-주소가-404일-때)를 참고하세요.

## 플레이

입장 메뉴는 온라인 대전(준비중), AI 연습전, 도감입니다. 연습전에서 탑·정글·바텀·서포터와 챔피언을 선택합니다. 추천 역할군은 선택을 제한하지 않습니다.

**일반 챔피언 20명:** 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르, **구보, 가환, 넬리, 에이해브, 루돌프, 묘, 동백, 동랑**. 도감에는 전체 31명의 기획을 수록합니다. 모제스·에즈라·알리사 3명은 도감의 조작·규칙 실험실에서 플레이할 수 있으며 임시 몸체를 사용합니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 유지 | 수동 기본 공격 |

좌표 생성형 기술, 좌표 지정 이동·순간이동 기술만 범위 표시 후 좌클릭으로 확정합니다. 파우스트·가환·동백 궁극기, 이상 장판, 동랑 나무·궁극기와 료슈·싱클레어·넬리·에이해브의 좌표 이동 등이 해당합니다. 나머지 방향 사격·본인 버프·대상 지정 사격은 빠른 시전입니다. 히스클리프는 우클릭 충전 후 **좌클릭 발사**. 루돌프 궁극기는 확대 지도에서 클릭 확정. 모제스·에즈라는 우클릭 드래그로 방향을 고르고 버튼을 놓으면 즉시 적용하며 드래그 없이 놓으면 취소됩니다. 구보의 아군 공격은 **Ctrl+좌클릭**, 아군 궁극기 지정은 **Ctrl+Space**입니다. 허용 체력은 기본 21% 이하, 전술기 버프 중 35% 이하입니다. 탄창 아래 전술기 유지 시간 게이지를 표시합니다.

## 전투·성장·상점

- 베기 무기는 좌우로 번갈아 휘두르고 찌르기·사격과 구분합니다. 검기, 피격 섬광·파편, 사망 위치의 시체를 표시합니다. 체력 숫자·탄창·정신력·중첩은 챔피언 머리 위에 표시합니다.
- 기본 공격의 탄창 소모 간격은 30% 증가하며 기존 고속 공격(0.4초 이하)은 유지합니다. **공격 중에는 장전이 멈추고 기존 부분 진행도는 보존**됩니다. 공통 장전 계수 0.52는 그대로입니다.
- 3초 비공격·비피격 후 초당 최대 체력 13% 자연 치유. 알리사 열화 자해는 비치명적이며 치유 대기에서 제외됩니다.
- 챔피언별 전투력·체력·이동속도가 레벨마다 증가하며 최대 10레벨입니다. 미니언 처치 시 근처 아군이 있으면 처치자가 80%, 아군이 합계 20%를 나누어 받습니다.
- 전투력·체력 강화는 **5단계**, 이동·장전·가속은 **3단계**. 가격은 단계별 160/260/400/580/800. 살아 있으면 부활소의 3초 비전투 상태, **사망 중에는 위치와 무관하게 강화·증강 구매 가능**. 물약은 살아서 부활소에 있을 때만 구매합니다.
- 증강 12종 중 최대 3개를 장착합니다. 전투 강화 3단계 / 체력 강화 3단계 / 이동·장전·가속 합계 3단계가 각 범주의 선택 조건입니다. 임시 가격은 구매 500, 판매 350 재화이며 교체할 수 있습니다. 쿨타임·최대 탄창·사거리·교전/생존 발동 효과를 실제 전투에 적용합니다.

v0.7은 요청한 10명의 챔피언 조정을 적용합니다. 넬리 기본 피해 210·성장률 6.6%, 가환 사거리 7.5·시선 5중첩·궁극기 0/0.75/1.5초 타격, 묘 4탄창·6초 궁극기, 뫼르소 피해 −15%·3탄창을 반영했습니다. 구보는 아군 처치 지점에서 7.5 부채꼴의 최대 체력 15% 고정 피해(최대 800)를 주고, 궁극기는 조준 후 탄환이 도착하면 적중합니다.

루돌프는 사슴뿔 지팡이·주황 효과와 감속→탄창 소거→쿨다운 역행·2.15초 저항 단계를 표시합니다. 동랑은 전투력을 체력·방어로 전환하고, 350 피해를 준 나무가 빛나는 욕망으로 변합니다. 기본 공격으로 7% 회복 수확, 궁극기 돌진 후 나무당 2.5% 회복이 가능합니다. 동백 궁극기는 즉시 360 피해·3초 장전 강화, 이스마엘은 작살 적을 바로 앞으로 끌며, 로쟈는 잭팟과 빗나가도 생성되는 빙판을 적용합니다. 세부 수치·해석은 [개발 명세](docs/PROTOTYPE.md)를 참고하세요.

중앙 전장 **83.2×46.8**의 라인·오브젝트 위치를 유지하고 본진 뒤 양쪽 날개와 위·아래 중앙의 직사각형 공간을 추가했습니다. 전체 경계는 **103.2×62.8**이며 추가 영역 사이의 빈 공간은 통과할 수 없습니다. 부활소를 더 뒤로 옮기고 귀환·부활·상점·회복·미니맵에 같은 좌표를 적용합니다. 라인 외곽과 새 공간에도 수풀을 배치합니다.

미니언은 **0초부터 0.35초 간격**으로 근접 3기 → 원거리 1기 → 공성 1기(매 3번째 웨이브)를 출격시킵니다. 교전 전에는 한 줄로 같은 경로를 따라갑니다. 이후 웨이브는 25초마다 시작합니다. 2분마다 체력 6%·공격력 5% 성장, 12분 상한과 근접 30%·원거리 20%·공성 50% 포탑 피해 감소는 유지합니다.

일반 중립 크립은 **20초**, 버프 크립은 **45초** 후 재생성됩니다. 본진 앞 2곳과 새 위·아래 캠프 2곳은 각각 중립 크립 2마리입니다. 버프 크립 체력은 **1662.5(+33%)**, 증폭·가호 유지 시간은 **60초**입니다. 증폭은 대상이 서 있던 위치에 원을 만들고 2.75초 후 공격, 가호는 전방 부채꼴을 표시하고 2.65초 후 공격합니다. 첫 적대 1.5초 후 패턴을 시작하고 이후 시작 간격은 5초이며 집중 중 받는 피해는 +20%입니다. 피해량은 미지정값으로 증폭 180·가호 160을 설정했습니다.

크립은 피격 전 중립이며 캠프 밖에서 적대로 1.85초 머물면 복귀합니다. 패턴은 사망·복귀·기절·침묵·강제 이동으로 취소됩니다. 크립 타이머와 5분 단일 보스는 유지합니다.

**적 포탑 하나를 파괴하면 본진 무적이 해제**됩니다. 포탑이 하나 남은 본진은 받는 피해가 50% 감소합니다. 본진을 파괴하면 즉시 승리하며, **20분**에는 생존 포탑 수 → 생존 포탑 체력 합계를 비교합니다. 양 팀 포탑이 모두 없으면 본진 체력을 비교하고 같으면 무승부입니다. 화면 시계는 남은 시간을 표시합니다.

## 개발·검증

Node.js 22 이상:

```bash
npm ci
npm run dev
```

기본 포트는 5173이며 `PORT=8080 npm run dev`로 변경할 수 있습니다. Codespaces 재연결 시 `node scripts/codespaces-start.mjs`가 서버를 재사용합니다.

```bash
npm run check
npm test
npm run build
python3 tests/browser_smoke.py
python3 tests/v04_browser.py
python3 tests/v05_browser.py
python3 tests/v06_browser.py
python3 tests/standalone_smoke.py
```

브라우저 검증에는 Python Playwright와 Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로·서버를 변경합니다. `?debug=1`로 테스트 상태를 열며 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. 규칙 테스트는 20명 각각의 60초 경기와 대표 4개 포지션의 10분 경기, 증강 발동·가격·재판매, 새 챔피언과 변경 규칙을 검사합니다.

`dist/index.html`과 `dist/city-border.html`은 코드·스타일·도감·**네 스프라이트 아틀라스**를 내장한 동일한 실행본입니다. 외부 요청을 차단한 sandbox iframe에서도 검사합니다. 실제 ChatGPT 미리보기에서 스크립트 실행을 허용한다는 뜻은 아닙니다.
