# 도시 경계 — 4vs4 MOBA v1.0.3

Project Moon 작품을 모티브로 한 비공식 팬 게임입니다. 초대 링크로 참가하는 유저 호스팅 최대4대4 온라인 대전, AI 대전과 시간 제한 없는 연습장을 지원합니다. 모든 경기는 3D 지형과 2D 본진·포탑·챔피언을 사용하는 2.5D로 진행합니다.

[v1.0.3 패치노트](docs/PATCH_NOTES_v1.0.3.md)에서 이번 업데이트 내용을 확인할 수 있습니다.

전체 효과와 수치는 [현재 구현 규칙](docs/CURRENT_RULES.md) 및 게임 내 도감에 수록합니다.

## 온라인 대전 공개 링크

참가자는 설치 없이 웹 링크로 접속합니다. 방장이 방을 만들고 초대 링크를 공유하면 됩니다. 직접 연결이 어려운 환경에서는 자동 중계로 연결하며 전투 계산은 방장 브라우저에서 수행합니다. 공개 주소 발급은 운영자가 한 번 배포해야 합니다. [온라인 배포·운영 안내](docs/ONLINE.md)에 Render 원클릭 배포와 Docker 설정을 제공합니다. 기존 단일 HTML과 GitHub Pages는 AI 대전·연습장에 사용할 수 있습니다.

## 서버와 독립된 무료 오프라인 페이지

GitHub Pages용 빌드는 AI 대전·연습장·도감을 지원하며 방 서버에 연결하지 않습니다. 메뉴의 **오프라인 파일 저장**으로 `city-border.html`을 내려받으면 인터넷이 끊겨도 파일을 열어 플레이할 수 있습니다. 온라인 서버의 메뉴에서도 **오프라인 버전** 링크로 이동할 수 있습니다.

배포 주소: `https://yiamuge.github.io/game_project/` (GitHub Pages 활성화 및 배포 성공 후 사용 가능). 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 한 번 설정하면 `codex/city-border-v0.2` 브랜치의 푸시마다 **Publish free offline game**이 최신 파일을 자동 배포합니다. 서버 실행이나 유료 웹 서비스가 필요하지 않습니다. 자세한 설정은 [오프라인 페이지 안내](docs/OFFLINE.md)를 참고하세요.

## ZIP 없이 실행·저장

[개발 브랜치](https://github.com/YiAmuge/game_project/tree/codex/city-border-v0.2)의 Code → Codespaces에서 환경을 엽니다. 초기 설치·서버 시작은 자동 처리합니다. `npm run update`는 현재 브랜치의 코드를 받고 게임 파일과 서버를 확인합니다. 소스 파일은 자동 저장되고 게임 페이지가 새로고침됩니다. 진행 중인 경기는 새로고침 시 초기화됩니다. GitHub 저장은 Commit → Push로 수행합니다.

Ports → 5173 → Open in Browser에서 현재 게임 주소를 엽니다. `npm start`는 서버를 시작·재사용하고, `npm run repair`는 소유권이 확인된 서버를 재시작하며, `npm run doctor`는 게임 파일·서버·외부 응답을 진단합니다. 브라우저 접속 문제는 [실행 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.

## 플레이

메뉴: 방 만들기 / 방 참여, AI 대전, 연습장으로 이동, 도감, 게임 종료. 선택 및 도감 챔피언은33명입니다. 도감은 기본 방어력 수치와 현재 기술, 몹·목표물·증강·규칙을 별도 페이지에서 확인합니다. 소라·얀·노스페라투는 기본 상태·변신 상태를 전환해 외형과 기술을 확인할 수 있습니다. 연습장에서는 작은 챔피언 픽창으로 내 챔피언 변경·아군/적군 AI 소환을 진행하고, 크립 초기화로 바늘이·바느질의 왕을 포함한 정원 전체를 복원합니다.

역할군은 챔피언의 플레이 성향입니다. 각 챔피언의 주·부 역할군과 추천 포지션은 선택 화면과 도감에서 확인합니다. 뫼르소는 보호·방해, 추천 포지션은 탑입니다. 추천 포지션과 관계없이 선택할 수 있습니다.

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 조준 |
| 좌클릭 | 수동 기본 공격 |
| Q / 휠클릭 · E / 마우스5 · R / 마우스4 | 공격 · 도움 · 후퇴 핑 (길게 누르고 드래그하여 대상 선택) |
| 우클릭 / Space | 전술기 / 궁극기 |
| 좌클릭 / 우클릭·Esc | 좌표 지정 기술 확정 / 취소 |
| Tab 유지 | 확대 지도·KDA·성장 수치·크립 타이머 |
| G / B | 상점 / 3초 귀환 |
| F12 / 화면의 ⛶ 버튼 | 전체 화면 |

얀·호엔하임 기본 공격과 히스클리프 전술기는 누른 채 충전하고 놓아서 사용합니다. 하단에는 패시브와 기본 공격·전술기·궁극기 칸이 표시되며, 패시브에 대기시간이 있으면 남은 시간을 표시합니다. 체력·탄창·정신력·충전량은 챔피언 머리 위에, 보호막은 체력바 안에 표시합니다.

## 전장과 연습장

전장은 본진·상하단 라인·정글·외곽 캠프로 구성됩니다. 첫 미니언은 3초에 출격하며 웨이브 간격은 25초입니다. 포탑 체력 5000, 본진 체력 6000. 20분 제한, 본진 파괴 시 즉시 승리합니다. 포탑 하나를 잃으면 본진이 공격 가능해집니다. 체력 35% 미만 본진은 10초 비피격 후 최대 체력 15% 보호막을 얻습니다.

본진 앞 캠프에는 굶주린 르카키, 중앙 캠프에는 시지프의 잔재가 등장합니다. 두 크립은 기본·공격 자세를 사용하며 발·점액 웅덩이가 지면에 맞닿습니다. 림버스 컴퍼니 건물에는 특수부대 미니언, N사 건물에는 정장 미니언이 배정됩니다. 양측 색은 아군 파랑·적군 빨강이며 건물 받침대도 지면에 배치하며 본진은 받침대 바닥 면의 중심을 원형 지면의 중앙에 맞춥니다. 포탑의 표시 높이는 챔피언의1.7배입니다.

연습장은 회복·피해, 크립, 대치 허수아비, 이동 표적, 미니언·포탑의 다섯 구역으로 구성됩니다. 시간 제한 없이 어디서나 무료 상점을 사용하며, 우측 상단의 접을 수 있는 옵션에서 무적·쿨다운·탄창·소환·AI·챔피언 변경·지도 이동 등을 조절합니다. 무한 허수아비 위에서 피해량·치유량을 확인합니다.

증강은 최대6개, 각 카테고리 일반 증강은 최대2개를 보유합니다. 딜리버리 캐리어 보유 시 카테고리 제한이 없습니다. 전투력·체력 강화 시술은 각 3단계, 이동속도·장전 속도·가속은 각 2단계입니다. 증강 21종의 효과·조건과 모든 챔피언 기술은 [현재 구현 규칙](docs/CURRENT_RULES.md)에 상세하게 설명합니다.

## 렌더링과 검증

일반 피격은 몸통에 붙는 흰색·회색 파편과 짧은 스파크로 표현합니다. 공격은 실제 반경·폭·방향의 안쪽 전체에 선명한 재질·검기·충격파를 표시하며, 파편은 높이 방향의 포물선 운동과 수평 감속·축소·투명도 감소를 사용합니다. 탄환·나이프·못·작살·거울 조각·얼음도끼는 재질과 궤적을 가진 별도 투사체로 표시합니다. 투사체는 기술별 표시 크기를 사용하며, 공격 판정 반폭은 기술에 설정된 폭의 1.1배입니다. 물·전류·얼음·나무·불꽃은 지정된 기술의 속성에 맞춰 표현합니다. 버프·보호막은 선명한 오라·외곽광을 사용하고, 공격 잔광과 몸통 하이라이트는 기술을 선명하게 비추며 합성 상한을 적용합니다. [챔피언별 시각 표현](docs/COMBAT_VISUAL_GUIDE.md)과 [이펙트 코드](docs/SKILL_VFX.md)에 자세히 설명합니다.

휘두르기·베기 공격은 무기별 최대 5프레임의 실제 위치를 연결하는 잔상을 표시합니다. 오래된 위치일수록 꼬리가 가늘고 투명하며, 무기 모션이 끝나면 0.12초 동안 사라집니다. 무기와 베기 이펙트의 색상을 사용하며 카메라 이동·창 크기 변경·일시정지에도 공격 위치를 따라 표시합니다.

돌진·도약은 실제 위치와 높이를 최대 5프레임까지 기록해 몸체 잔상과 연결 궤적을 표시합니다. 오래된 부분은 가늘고 투명해지며 종료 후 0.18초간 사라집니다. 스타벅의 궁극기는 상승·수직 착지에도 잔상을 사용하고 공중에서는 무기를 표시하지 않습니다.

벽·포탑이 챔피언을 가리면 반투명해집니다. 캐릭터와 몸통 표식·체력 UI는 지면 좌표에서 투영한 평면으로 표시하고, 공격 범위·장판은 지면에, 투사체는 높이가 있는 비행 궤적으로 표시합니다. 3D 배경은 여유 영역을 포함해 캐시하며 카메라 이동·가림 상태·건물 파괴에 맞춰 갱신합니다. 3D 화면의 해상도 예산은 921600픽셀입니다. Three.js는 로컬 번들로 포함합니다. WebGL 지원 브라우저가 필요합니다.

```sh
npm ci
npm run check
npm test
npm run build
PORT=5180 npm start
MOBA_TEST_URL=http://127.0.0.1:5180 python tests/v25_browser.py
```

`npm run build`는 외부 파일 없이 열리는 `dist/city-border.html`과 `dist/index.html`을 생성합니다. `node scripts/sync-content.mjs`는 도감의 기술 설명으로 툴팁·규칙 문서를 생성합니다. Three.js 의존성 갱신 후 `npm run vendor`로 로컬 번들을 생성합니다.

상점은 어디서나 열람하며, 생존 중 거래와 강화 시술은 부활소에서 이용합니다. 아이콘에 커서를 올리면 우측에 상세 효과가 표시됩니다. 더블클릭 또는 구매 버튼으로 구매하고 판매 버튼으로 판매합니다. 카테고리 테두리는 전투 주홍색·생존 연두색·기술 하늘색입니다. 연습장에서는 시술 일괄 구매·판매, 레벨 1~10 조정과 경험치 중단을 지원합니다. Q·E·R을 짧게 눌러 공격·도움·후퇴 신호를 보냅니다. 길게 누르고 커서의 아이콘으로 드래그한 뒤 놓으면 대상을 지정하며, 드래그 없이 놓으면 취소됩니다. TAB은 확대 지도와 점수창을 표시합니다. 고위험 작전용 장비의 침투는 어디서든 B로 1.75초 집중 후 사라져 WASD로 사거리 35 안의 착지 위치를 옮기고, 우클릭 유지로 정밀 이동하며 좌클릭으로 확정하면 0.5초 후 나타납니다.

전장은 검붉은 연기가 덮인 도시의 마천루 옥상입니다. 상단 전체에는 하나의 도시 전경이 펼쳐지고, 하단에는 커다란 창문 외벽이 아래로 이어집니다. 외벽 맨 아래와 푸른연기에는 짙은 푸른 연기를 표시합니다. 옥상은 회색 콘크리트·낡은 금속 질감을 사용합니다. 벽에는 창문·환풍구·작은 간판이 배치됩니다. 반물질 옷은 옷의 형태로 모였다 흩어지는 보라·청록색 입자 아이콘입니다. 재질과 아이콘은 오프라인 실행 파일에도 포함됩니다.

넬리 전술기와 개화 소라 전술기는 남은 충전 횟수와 다음 충전까지의 시간을 함께 표시합니다. 사용 가능한 충전이 남으면 대기시간 숫자가 표시되어도 즉시 사용할 수 있습니다.

상단 바늘이는1분30초에2기가 등장하며 각각25XP·10재화를 준다. 처치 자리에서20초 뒤 재생성하며 캠프 전체에서 추가4기까지만 생성된다. 3분30초에 체력3600의 바느질의 왕이 등장한다. 왕은2초마다 주변 모든 챔피언 방향으로 관통 바늘을 발사하고 체력30% 손실마다 방어·공격 속도가 강화된다. 소환 바늘이는 보상이 없다. 왕 처치 보상은 팀 전원125XP·200재화와 영구 땀수!다. 중앙 보스 ‘다시 쌓인 것’은5분에 등장하고 빛바랜 원단을 준다.

픽 화면의 좌우4개 슬롯에서 내 챔피언과 포지션, 아군3명·상대4명의 AI를 지정합니다. AI는 챔피언 지정·무작위·없음을 선택할 수 있습니다. 중앙 목록만 스크롤되며 확정 버튼은 하단에 고정됩니다. 선택 포지션에 맞는 챔피언에는 추천 표시가 붙고, 역할군 필터는 주 역할군과 부 역할군을 나눠 보여줍니다. 온라인 방도 같은 픽 목록을 사용하며 하단에서 채팅할 수 있습니다. AI 대전과 연습장 모두 독립된 전체 화면으로 선택합니다.
