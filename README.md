# 도시 경계 — 4vs4 MOBA v0.3

Project Moon 작품을 모티브로 한 비공식 팬 게임 개발 프로젝트입니다. 첨부된 기획서 2종과 이후 사용자의 변경 요청을 기준으로 개발합니다.

## ZIP 없이 수정하고 실행하기

GitHub의 **`codex/city-border-v0.2` 브랜치**에서 **Code → Codespaces → Create codespace on this branch**를 누르세요. 브랜치 이름은 이전 버전을 유지하며 현재 소스는 v0.3입니다. 이미 이 브랜치의 Codespace를 사용 중이면 먼저 작업 내용을 Commit한 뒤 **Source Control → Pull**로 변경을 받으세요.

환경이 준비되면 **Ports → 5173 → Open in Browser**로 게임을 엽니다. 파일은 800 ms 후 자동 저장되며, 저장하면 게임 화면이 약 1.2초 안에 새로고침됩니다. 이때 연습 경기는 초기화됩니다. **GitHub에도 변경을 보관하려면 Commit → Sync Changes / Push**가 필요합니다.

자세한 절차는 [브라우저 개발 안내](docs/LIVE_DEVELOPMENT.md)에 있습니다. 이 구성은 Codespace 생성과 Pages 게시를 자동으로 완료했다는 의미는 아닙니다.

## v0.3 플레이

입장 메뉴에서 **온라인 대전(준비중)**, **혼자서 AI와 연습전**, **도감**을 선택합니다. 연습전은 포지션과 챔피언을 골라 플레이어 1명 + 봇 7명으로 시작합니다.

- **챔피언 12명**: 파우스트, 이상, 싱클레어, 뫼르소, 돈키호테, 료슈, 홍루, 히스클리프, 이스마엘, 로쟈, 오티스, 그레고르.
- **포지션**: 탑 상단 1vs1, 정글 크립 사냥·갱킹, 바텀·서포터 하단 2vs2. 추천 역할군은 선택을 제한하지 않습니다. 서포터 봇은 주기적으로 로밍합니다.
- **조작**: WASD 이동, 마우스 조준, 좌클릭 연속 공격, 우클릭 전술기, Space 궁극기, 1 소모품, **Tab을 누르는 동안 확대 지도·양 팀 K/D/A·능력치 증가량**, **G 부활소 상점**, Esc 취소·일시정지, F 전체 화면.
- **HUD**: 좌측 상단 미니맵, 하단 중앙 기술 쿨타임, 좌측 하단 소모품, 우측 하단 최근 버프 최대 3개.
- **자연 치유**: 3초간 공격·외부 피격이 없으면 초당 최대 체력의 13% 회복. 공격이 빗나가도 대기시간이 시작됩니다.
- **공통 장전 변경**: 장전 성능 −20%; 동일 조건의 충전 간격은 이전의 1.25배. 도감의 미구현 챔피언에도 공통 변경을 명시합니다.
- 부활소에서 3초 비전투 상태일 때 강화·물약 구매. 양쪽 적 포탑 파괴 후 본진 공략. 30초 웨이브, 5분 중앙 보스, 10분 목표물 판정.

**도감**에는 챔피언 31명, 몹·목표물 10종, 소모품 7종, 게임 규칙이 있습니다. 회복 물약만 구매·사용 가능하며 나머지 소모품은 미구현으로 표시합니다.

도감에서 루돌프·모제스·에즈라·알리사·구보를 검색하면 **조작·규칙 실험실**에 입장할 수 있습니다. 이 5명은 임시 외형을 쓰는 검증용 구현이며 일반 선택창의 12명과 구분합니다.

- 루돌프: Space → 확대 지도 좌클릭으로 전역 궁극기 확정. Esc 또는 우클릭 취소.
- 모제스: 우클릭을 누른 채 상하좌우로 끌어 곰방대 선택. 에즈라: 좌우로 끌어 무기 교체. 드래그 없이 놓으면 비용 없이 취소.
- 알리사: 자연 치유 조건을 만족하면 열화 전부 제거. 열화 자해는 비치명적이며 치유 대기를 갱신하지 않습니다.
- 구보: **Ctrl+좌클릭**으로 최대 체력 17% 이하 아군을 명시적으로 공격. **Ctrl+Space**는 같은 조건의 아군 궁극기 지정입니다. 일반 공격은 적을 향합니다.

PC 키보드·마우스 기준입니다. 작은 화면 배치는 지원하지만 터치 이동 조작과 사운드는 없습니다. 자동 조준과 온라인 8인 대전은 보류 중입니다. 원작 특징을 반영한 2등신 팬 아트와 독립 회전 무기를 사용합니다.

## 개발과 빌드

Node.js 22 이상:

```bash
npm ci
npm run dev
```

기본 포트는 **5173**. 다른 포트는 `PORT=8080 npm run dev`. 개발 서버 자체에는 외부 런타임 의존성이 없습니다. Codespaces 재연결 시 `node scripts/codespaces-start.mjs`가 기존 서버를 재사용합니다.

```bash
npm run check
npm test
npm run build
```

빌드용 esbuild는 잠금 파일에 고정했습니다. `dist/index.html`과 `dist/city-border.html`은 코드·스타일·두 스프라이트 아틀라스·도감 데이터를 내장한 같은 실행본입니다. 외부 런타임 파일 요청이 없습니다.

개발 서버 실행 중 실제 브라우저 검증:

```bash
python3 tests/browser_smoke.py
python3 tests/standalone_smoke.py
```

브라우저 테스트에는 Python Playwright와 Chromium이 필요합니다. `CHROMIUM_PATH`, `MOBA_TEST_URL`로 경로와 서버를 바꿀 수 있습니다. `?debug=1`은 테스트용 상태 접근을 허용합니다. 캡처는 Git에서 제외된 `artifacts/`에 저장합니다. 단일 HTML 테스트는 외부 요청을 차단한 sandbox iframe에서 실행하며 실제 ChatGPT 미리보기의 동작을 보장하는 테스트는 아닙니다.

규칙 테스트에는 자연 치유, 17% 아군 조건, 장전, 드래그 취소, 전역 궁극기, 신규 기술과 변신, KDA, 모든 12명의 60초 봇 경기, 대표 4개 포지션의 10분 경기가 포함됩니다. 전체 테스트는 약 40초가 걸립니다. 자동 검증은 실제 플레이를 통한 밸런스 검증과 구분합니다.

## 온라인 주소로 게시하기

개발 브랜치를 `main`에 병합한 뒤 **Settings → Pages → Source: GitHub Actions**를 선택하고 **Actions → Publish browser game → Run workflow**로 첫 배포를 실행합니다. 이후에는 `main` 푸시로 검사·빌드·Pages 게시가 실행됩니다. 실제 주소는 성공한 배포 작업 결과에 표시됩니다. 자세한 안내는 [브라우저 개발 안내](docs/LIVE_DEVELOPMENT.md)를 참고하세요.
